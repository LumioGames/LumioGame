## S15A-1: whole original World fails the official Effect preflight first

**P1, release-boundary draft lines 42–47.** `ExpandedReleaseRejectsTheWholeImmutableOldFiveWorldWithoutPublishingIt` calls the actual public engine restore helper but requests `AssertOwnerFailure<FormatException>` and asserts `bad_delta_envelope`. The adjacent comment assumes only contact capacity can differ in this fixture's generated Effect descriptors. That assumption is false for the actual schema15 integration: type 10112 was added to the generated Effect registry.

The real preserved artifact is `games/101-bomber/.artifacts/resource-contact-world/old-world-cap5-0bb1c9bca38e454fb187e5874ec84c44/original.lwm`, **21,487 bytes**, SHA256 `6a0e5a671cdb89a003c4567ccefa9534481c0fcd48e147b10c583d8aabd755a8`. Its metadata retains SHA256 `d9512037e1f85c11775ced7271a31ceb970e6947bcf67b9789b00060d25fb573`; all 31 saved export files retain their original hashes. Read-only decoding confirms one original contact field with capacity/count 5/5 and the untouched complete Effect section beginning at byte 21,435.

The stored Effect registry hash is `cb9a51c25bc99f718f39ae87584d443ed8b2e7245f74e13b1befa98e5d1c4dcc`. Hashing the complete exact current official canonical descriptor bytes in registry type order gives `e6714093c5a8c4ab52ca9fcb9722ef5f6664670be999c079781cc23d4f590f37` for all twelve types. The same current descriptors with only 10112 excluded give exactly the stored old hash. This is a computation on original artifact/generated bytes, with no World rewrite, synthetic payload, replacement registry or Runtime execution.

Selected official07 `WorldManager.Lifetime.cs` prepares `World.PrepareEffectRestore` before it returns the action that invokes `HydrateRows`. `GasWorldContext.Persistence.CheckHeader` compares the stored hash with `gas.Types.EffectRegistryHash()` and throws `FiniteEffectCodec.Invalid()` on disagreement. That factory returns **InvalidOperationException("effect_restore_invalid")**. Only after this preflight succeeds does `HydrateRows` invoke generated component RestorePersist, and only after all restores does it call OnHydrate. Therefore this original old World cannot reach the contact-capacity mismatch under the current twelve-effect registry.

The existing assertion fails safely; it would not mislabel an earlier refusal as success. It is nevertheless the wrong expected boundary for this actual release and is not accepted as a valid whole-World contact-envelope test. Correct this Fact to require the exact official Effect preflight refusal, with exception origin/stack or equivalent existing stage evidence, while preserving the original artifact and raw typed-container Fact. Keep the claim limited to whole-World release rejection before hydration. Do not patch the original Effect header, remove 10112, bypass preflight, or edit Runtime to make the test reach a preferred branch. A narrower contact-capacity RestorePersist boundary needs a separately qualified compatible fixture/executor and must not be presented as this original whole World.
