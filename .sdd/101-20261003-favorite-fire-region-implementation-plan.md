## Exact representation

The entire cast lease is one bounded record per Participant, at most P records. A second cast by that Participant is unavailable before all previous debt closes, even if CD elapsed. This is a capacity/unknown-commit rejection before any side effect, not a timer clearing debt. Lease fields are: full Participant/Life; LifeGeneration/MatchId/ChainId; captured held skill, bound active level and Fire family; cast Tick/duration/CD/region duration; full 10111 handle plus immutable captured Aura WorldId; phase; issued ordinal count; one pending birth Tick/X/Z/mask/ordinal/submitted witness. All integer additions and conversions are checked. The accepted Favorite flag and source are immutable across slot exchanges and successor creation.

The codec is closed ASCII with exact properties and canonical IDs, duplicate-property rejection, unknown-field rejection, exact array shape and UTF8-byte validation before any write. Source Life must have the correct world identity but may later be retired; live/current is required for *new emission*, not historical source validation. A submitted cast with absent/fullhandle ambiguity cannot become Prepared or reapply on restore. Paired checkpoints may rebind only the actual restored GAS World's WorldId after matching instance, generation, source, target, type, payload, AppliedTick and EndTick. Captured parent WorldId in an already emitted child's immutable payload is historical and is never rewritten to a new WorldId. Validate that child's exact restored payload against its own captured fields; only its current lifetime handle rebinds. New births after a legitimate rebind use the actual current parent handle. Cast matching continues to pin parent instance/generation and original cast source/timing; it may not impose equality of every historical child WorldId with today's parent WorldId. True repeated paired-restore tests must prove this distinction. Runtime-only activity restore remains rejected.

Each birth owns a single BomberFireZoneEntity. Existing fields retain meaning: Owner=Participant; SourceSkill=4; SourceLife/full generation/match/chain captured at cast; LogicTransform is center; Direction=0, Length=3; CoverageMask contains only bits0..8; PromiseToken is a canonical fixed ASCII key derived from Participant+Match+Chain+ordinal. Bit index is `(dz+1)*3+(dx+1)`. Mask includes actual open obstacle cells from the shared Native photo, clipped to the map. A zero mask is an explicit emitted empty region, not an omitted ordinal. Future terrain changes do not mutate the admitted coverage snapshot.

Append eleven Persist fields to FireZoneState: RegionOrdinal(int); DurationTicks(ulong); AuraEffectWorld/Instance(ulong), AuraEffectGeneration(uint); LifetimeEffectWorld/Instance(ulong), LifetimeEffectGeneration(uint); LifetimeOutcome(int); BirthSubmitted(bool); RegionCoverage(bool,Aoi). UntilTick is zero until genuine Initial Applied, then equals AppliedTick+DurationTicks. FromTick is the immutable submitted birth Tick and must match actual AppliedTick. Outcome states distinguish Prepared, Submitted, Applied, known Reject and matching Expired; no transition infers success from elapsed wall time. Existing SourceLife/Generation/Match/Chain and CoverageMask become Aoi through the formal compatibility change, as do the actual region/source stamp needed by observers. Full GAS handles remain private. RegionCoverage is a formal Game shape discriminant, true for these nine-bit regions and default false for historical line content. Thus a genuine empty mask emits no cells, while a legacy mask0 line retains its prior interpretation. No Direction value is borrowed as a hidden shape ID.

10112 parameters are privately declared as Duration/Fx, full Participant/Life/generation/match/chain, full parent Aura handle, target Zone, ordinal, center X/Z, mask, BirthTick. Context.Source is the original Life; Context.Target is the issued region ID. The promise token is derived from these complete values and need not be duplicated as arbitrary text in the Effect payload. No periodic contribution or gameplay attribute write is declared. Generated codec maximum must be measured; the scalar/32-byte-Fx layout is 160 bytes including its 4-byte string prefix (7 UInt64×8 + 3 entity×16 + 5 UInt32/Int32×4 + 4+32), below the current192 allowance if official encoding agrees. Root's actual generated diagnostics supersede that static count.

Retain every published region belonging to an open cast, including expired semantic regions, until the whole cast can close. This allows all-row count/ordinal/fullsource validation without storing 110 full result records in FireTrailPromises. Release the cast's entire credit only when emission ended positively (actual Aura terminal or actual source death), all emitted regions have matching terminal/native expiry, no unresolved publication, and no FireFacts/exposure/terrain receipt references remain. Then one normal structural batch retires the regions and lease. Unknown, late Original, historical source retirement and round change cannot discard a debt.
