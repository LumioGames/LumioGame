# 起床战争俯视改编 · 方向稿

> **状态**：设计中（方向级，不展开细节）
> **序位**：阶梯 ②
> **上游**：[`../product-direction.md`](../product-direction.md)、[`../art-direction.md`](../art-direction.md)

## 1. 使命

第一款有**深度**的产品。证明我们能承载**建造 + 团队配合 + 局内经济**，而不只是快节奏小游戏。

新增的挑战维度：长局（15–20 分钟）、队伍协作、建造深度。

## 2. 核心改编：把垂直落差改成水平空隙

俯视角会削平 Bed Wars 的高低差，这是这次改编最大的问题。

但仔细拆解会发现：**Bed Wars 的核心张力不是"高"，而是"跨越一段危险的空隙，去砸别人的床"。**

- 搭桥过去的紧张感 → 来自**暴露在外、无处可躲**
- 桥被拆掉的绝望 → 来自**退路被断**
- 从桥上掉下去 → 来自**掉出局，要重新走一遍**

这三件事**全都不依赖"高度"**，只依赖"空隙"。

> **解法：把空隙从垂直改成水平。**
> 岛屿分布在同一平面，之间是虚空/深渊，玩家搭桥跨越。掉下去即出局（或送回己方岛）。
> 高度只用来做局部掩体和小高台，不承担核心张力。

这样 ② 就**不必等"多层地形显示"这个技术难题解决**，风险大幅下降。俯视角下看桥、看桥上的人、看桥被拆，其实比第一人称更清晰。

## 3. 局制规格（暂定）

| 项 | 规格 |
|---|---|
| 人数 | **16 人**（4 队 × 4 人） |
| 局时 | 15–20 分钟 |
| 地图 | 中央资源岛 + 4 座队伍岛 + 若干中立小岛 |
| 胜负 | 摧毁对方床后再击杀即淘汰；最后存活队伍胜 |

## 4. 三个核心系统

### 4.1 资源经济

队伍岛上的**生成器**持续产出基础资源；中央岛产出稀有资源。这是"守家 vs 出击"的核心张力来源。

### 4.2 建造

- 用资源放置方块，主要用于**搭桥**和**加固床周围**
- 方块有材质分级（易碎 / 耐爆 / 抗火），对应不同成本
- 建造直接落在引擎为"消耗资源改方块"设计的主路径上

### 4.3 床

床是可破坏目标。**床在 = 无限复活；床没 = 死一次出局。**

床周围的加固与拆解，是这个玩法最主要的攻防博弈。

## 5. 相对 ① 的新增维度

| 维度 | ① 炸弹人 | ② 起床战争 |
|---|---|---|
| 局时 | 2–3 分钟 | **15–20 分钟** |
| 单位 | 个人 | **队伍（4人）** |
| 方块操作 | 只破坏 | **破坏 + 建造** |
| 经济 | 无 | **局内资源经济** |
| 复活 | 无 | **有条件复活** |

## 6. 待解决

| 问题 | 说明 |
|---|---|
| **断线重连** | 20 分钟局时，掉线会毁掉一整局。引擎目前无快速重连，见 [`../risks-and-engine-asks.md`](../risks-and-engine-asks.md) |
| 掉下去的惩罚 | 直接出局 / 送回己方岛，两种手感差异巨大，需原型验证 |

| 观战与死亡等待 | 出局后可能要等 15 分钟，必须设计观战体验 |
| 队伍沟通 | 无语音时的快捷标记系统 |
