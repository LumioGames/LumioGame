# 世界观设定:动物玩偶派对

> **状态**:设计中
> **适用范围**:Lumio 全线产品(换游戏不换世界)
> **上游**:[`product-direction.md`](product-direction.md) · 定调依据 [ADR 0008](../../.spec/decisions/0008-worldview-animal-plush-party.md)

## 0. 一句话

**一盒被赋予生命的动物玩偶,在积木搭成的桌面世界里开派对。**

动物回答「谁」——物种给识别度、表情给情绪、玩偶给皮肤空间;玩具回答「在哪、为什么」——体素 = 积木,俯视 = 俯瞰桌面,多款小游戏 = 一盒桌游。后者与「开源平台托多款游戏」的产品定位语义同构:每上一款新游戏,就是玩具盒里多了一套新桌游。

## 1. 世界规则

| 规则 | 口径 | 服务什么 |
|---|---|---|
| 世界是桌面 | 对战场地是搭在桌面软垫上的积木棋盘;桌面、垫布可以入画,作为「世界边缘」 | 给体素地形与俯视相机一个天然解释 |
| 地形是积木 | 体素块 = 积木/方块玩具;破坏 = 积木被炸飞、缺一块 | 破坏玩法的读数与反馈 |
| 角色是活玩偶 | 动物造型的玩偶活化:缝线、豆豆眼、毡布/软胶材质细节是「玩偶感」的载体 | 识别度、亲和力、材质换皮想象 |
| 道具是玩具 | 炸弹是圆滚滚的玩具炸弹(冒火花引线),道具走「玩具化」造型 | 统一造型语言 |

## 2. 表现基线(内容评审的否决依据)

- **死亡 / 损失**:玩偶散架、棉花飞出、零件弹开——夸张、滑稽、**不血腥**。任何写实伤害表现直接否决。
- **重生**:语义 = 「重新摆上桌」。
- **情绪**:休闲、轻松、愉快;紧张感允许来自玩法(如鸭科夫的撤离张力),不来自视觉恐怖或压抑。

## 3. 三款产品的世界观表达

| 产品 | 世界观表达 |
|---|---|
| ① 炸弹人 | 玩偶们的积木棋盘炸弹赛;帽子计分(ADR 0006 / 0011)与「玩偶戴帽 / 被炸摘帽」天然贴合,帽子塔就是玩偶头上的显赫标志;装备 = 玩偶身上的玩具配件(炸弹形态换壳、技能是小道具),帽王光柱 = 打在玩偶头上的聚光灯,补给 = 分区里等着被敲开的小玩具箱与定时空投进积木围栏的大玩具箱（ADR 0014）,场景材质 = 玩具盒里的材料(积木、木头玩具、铁皮、水方格、鞭炮),受伤 = 玩偶露线露棉花三档、心归零才散架(ADR 0012,表现归美术) |
| ② 起床战争 | 两队玩偶保卫各自的「床头堡」;搭桥 = 铺积木 |
| ③ 鸭科夫 | 橡皮鸭潜入玩具仓库摸零件;「看着人畜无害、玩着心跳加速」的反差由玩具属性天然承接,损失的「心疼」落在玩偶散架上 |

## 4. 待定项(不锁,后续设计再收)

| 待定 | 说明 |
|---|---|
| 角色阵容 | 首发有哪些物种玩偶;鸭是 ③ 的锚点,①② 的默认阵容未定 |
| 命名体系 | 世界、角色、地点的命名语言未定 |
| 主视觉 IP | 是否立一只「门面玩偶」未定 |
| 皮肤体系 | 「材质换皮」(毛绒版 / 木头版 / 软胶版)仅为候选想象,且被账号持久化(risks A5)阻塞 |

> 视觉如何呈现这个世界(色板、描边、质感)归美术比稿,见 [`art-style-pitch.md`](art-style-pitch.md);本稿只管设定与表现基线。
