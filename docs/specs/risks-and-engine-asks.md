# 风险清单与引擎侧需求

> **状态**：设计中
> **用途**：汇总策划侧已识别的风险，以及需要提给引擎侧的硬需求
> **上游**：[`product-direction.md`](product-direction.md)

## 0. 说明

本文的"引擎现状"来自对 8 个仓库的代码与文档调研（2026-08-28），**需与引擎侧当面确认后再作为承诺依据**。调研可能与团队的在途工作不同步。

---

## 一、需要提给引擎侧的硬需求

按**产品阶梯的依赖顺序**排列。

### A1 · 网络传输（① 的前置）

**现状**：客户端目前只有内存回环传输（LocalEmbedded），没有真实的 socket 网络代码；服务器仓库是零代码。

**诉求**：真实网络传输是**任何联机产品的前置**，包括 ①。

### A2 · Rust ↔ C# 的桥（① 的前置）

**现状**：负责导出统一入口的引擎打包仓库零代码；底层 Rust 仓库刻意还没导出 C 接口（甚至有测试专门禁止提前导出）。

**诉求**：这条桥不通，C# 玩法层就拿不到体素能力。**是全系统的前置。**

### A3 · 渲染与 Unity 工程（① 的前置）

**现状**：全仓库搜不到 sprite / camera / 渲染管线任何字样；Unity 工程尚未建立，Unity 版本与渲染管线均未选型。

**诉求**：
- Unity 工程与渲染管线选型的**时间点**
- 谁负责实现 [`art-direction.md`](art-direction.md) 里的相机与描边方案

> **这一条对策划影响最大**：画面是 ① 的核心验证目标，但渲染是完全空白的地基。

### A4 · 断线重连（② 的前置，③ 的**红线**）

**现状**：架构明确写着 V1 不提供快速重连，掉线后必须重新完整握手。

**诉求**：

| 产品 | 影响 | 判定 |
|---|---|---|
| ① 炸弹人（3 分钟） | 掉线等下一局 | 可接受 |
| ② 起床战争（20 分钟） | 掉线毁掉一整局 | 很难受 |
| ③ 逃离鸭科夫（30 分钟 + 死亡掉装备） | **掉线 = 玩家资产损失** | **会让人退游，立项前必须解决** |

**这是 ③ 的红线需求。**

### A5 · 账号级持久化数据（③ 的前置）

**现状**：架构里有"单局存档 / 迁移"，但**没有"玩家账号资产"这一层**。

**诉求**：仓库、出装、货币、进度这类跨局数据，需要一个明确的归属和数据模型。**这是 ③ 最大的未知数**，见 [`duckoff/direction.md`](duckoff/direction.md) §4。

### A6 · 匹配系统（增长期需求）

**现状**：全仓库没有任何匹配 / 大厅相关代码。

**诉求**：首发用**房间码**可以完全绕开，不阻塞 ①。但用户量起来后需要匹配。**不紧急，但要进路线图。**

## 二、策划侧自己承担的风险

### B1 · 画面组合可能根本不好看 —— **最高优先级**

「3D 体素 + 2D 角色 + 俯视角」几乎没有先例。**万一不好看，越晚发现越贵。**

**应对**：抛弃型原型（纯 Unity、单机、不接引擎），只回答"好不好看、好不好玩"。
**验收**：截图给不认识这个项目的人看，问"这好看吗"、"这是什么游戏"。

> 注：当前决策是**先写完整策划案、再做原型**。本文档完成即意味着原型可以启动。

### B2 · 模式数据格式表达力不足

如果 L2 的模式格式设计得太窄，后面开放 UGC 要推翻重来——在这套架构里属于破坏性变更，代价很大。

**应对**：在 ① 期间就设计模式数据格式，见 [`ugc-ladder.md`](ugc-ladder.md) §0。

### B3 · 移动端不能假设成立

架构评审明确写着移动端的内存 / 启动 / 热更预算**未经验证前不作为默认能力**。

**应对**：Windows 优先是对的。移动端操作方案在 ① 的设计里已经考虑（虚拟摇杆 + 两键），但**不承诺首发上移动端**。

### B4 · 长局的观战体验

② 出局后可能要等 15 分钟，③ 可能等更久。**死亡等待是长局产品的隐形流失点。**

**应对**：② 和 ③ 的设计稿必须包含观战体验章节，不能留白。

### B5 · 三款产品的资产复用度

平台定位要求多款游戏共享美术观感与资产。如果三款各做各的，平台叙事就垮了。

**应对**：[`art-direction.md`](art-direction.md) 是三款共用的强制规范；角色按 8 向制作以保证跨产品复用。

## 三、优先级汇总

| 级别 | 项 |
|---|---|
| **阻塞 ①** | A1 网络传输、A2 Rust↔C# 桥、A3 渲染与 Unity 工程 |
| **① 期间必须并行** | B1 画面验证、B2 模式数据格式设计 |
| **阻塞 ②** | A4 断线重连 |
| **阻塞 ③** | A4 断线重连（红线）、A5 账号级持久化 |
| **进路线图** | A6 匹配系统 |
