## 0. 比稿边界(已锁,候选不得越界)

- 卡通基调;休闲、轻松、愉快;娱乐社交向。
- 暖色调亲和情绪 + Q 版比例圆润造型(取自用户参考截图;不取其软渲染与 3D 角色)。
- 产线:**AI 主产能**(生图 / 生模型);场景体素 3D、单贴图、无 PBR;角色 2D + 少量动画,结构从简。
- 产品硬约束:俯视角玩法可读性、多人同屏识别、Windows 优先。
- 评估轴 = **AI 产线一致性 × 竞技可读性 × 情绪贴合**;运行时性能三方向几乎相同(单贴图体素 + billboard sprite),不作区分轴。

## 1. 三个候选方向

| | A · 暖软绘本 | B · 明快硬描边 | C · 玩具质感 |
|---|---|---|---|
| 一句话 | 奶油暖色 + 柔和有限明暗 + 细描边,绘本里走出来的派对 | 粗描边 + 高饱和色块 + 二值 cel,周六早晨动画能量感 | 塑胶 / 毛绒 / 木头伪立体质感,真实玩具摆上桌 |

**共通产线保底**:8 向 sprite 一致性是 AI 生图公认短板,通用方案是「AI 出概念定风格 → AI 生简模(或人工低模)→ 引擎内渲 8 向 sprite sheet」;B 纯 2D 生图可撑,A / C 建议按渲染管线预留。

## 2. 方向深描(视觉基准 · 世界观玩法贴合 · 风险)

> 把 §1 总表展开成可单独评审的方向档案。「贴合度」对照两份已定调文件:世界观四规则与表现基线([`worldview.md`](worldview.md) §1–2,ADR 0008)、炸弹人五支柱([`bomber/design.md`](bomber/design.md) §3,ADR 0006)。三方向的图底分离手段结构性不同,是贴合度差异的根源:

```
俯视同屏下「角色从地形里跳出来」靠什么(每方向只有一条主通道):
A 暖软绘本   → 色彩分层:角色饱和度高一档,地形提明度降饱和
B 明快硬描边 → 线宽分层:角色粗描边,地形细描边/仅勾轮廓
C 玩具质感   → 材质分层:角色毛绒/软胶高光,地形亚光积木
```

### 2.A 暖软绘本(Cozy Storybook)

**视觉基准**

| 轴 | 基准 |
|---|---|
| 色彩 | 奶油底暖色域(cream → honey → apricot),整体高明度、柔对比;冷色只作小面积点缀(leaf green 类),禁大面积冷色块。角色层饱和度必须比地形层高一档——这是纪律条款不是偏好(见风险) |
| 材质 | 手绘笔触感平涂 + 柔和两档明暗;不描写实物质感,是「纸上颜料」不是「实物材质」;贴图保留笔触纹理 |
| 轮廓 | 细描边(暖棕非纯黑,线宽约 B 的 1/2–1/3);造型语言 = 圆角一切,体素块做微圆角;剪影靠「胖」不靠「线」 |
| 光影 | 固有色 + 一档暖阴影(偏暖不偏灰);无投射光、无高光点 |

**世界观 × 玩法贴合**

- 情绪(比稿边界「休闲轻松愉快」):三方向最贴,绘本暖正中靶心。
- 玩偶感(worldview「角色是活玩偶」):中。绘本插画画布偶可信,但细线 + 平涂会把缝线/毡布这类材质细节压成淡装饰——玩偶感主要靠造型撑,不靠质感;而 ADR 0008 明言「玩偶感」依赖贴图细节质量。
- 积木感(worldview「地形是积木」):可信但偏软——微圆角 + 笔触贴图读作「画出来的积木」,破坏读数(缺一格)的锐度低于 B。
- 帽子计分乱斗(支柱 1/2「帽子塔就是计分板、帽王更显眼」):**三方向唯一直接顶撞支柱的弱项**——柔和色域下帽子塔远距对比先天不足,须给帽子留专用高对比色并执行饱和度纪律,否则中途进场者读不出谁在赢(支柱 4 连带受损)。
- 死亡表现(表现基线「散架不血腥」):星星/云朵软形状烟贴合,棉花飞出可自然融入。

**风险**:① 批次漂移——软渐变是 AI 批次一致性最不稳的形态;② 角色跳出度依赖纪律条款,一松就糊;③ 帽子塔远读(上条);④ 笔触贴图平铺重复感,需 tile 变体压制。

### 2.B 明快硬描边(Bold Pop)

**视觉基准**(详细条款见存档稿 [`art-direction.md`](art-direction.md),全文即本方向参考)

| 轴 | 基准 |
|---|---|
| 色彩 | 高饱和平涂色块,暖色主导(sunshine / tangerine 打底,sky / grass 点缀);有限色板全局统一,单资产不得自带色板 |
| 材质 | 无材质描写,纯图形语言;平涂 + 二值 cel,「周六早晨动画」的赛璐璐质感 |
| 轮廓 | 粗深描边(ink 近黑)是语言本体:角色粗边、地形轻边——描边是缝合 2D 角色与 3D 方块的针脚(旧框架核心洞见,平等参赛) |
| 光影 | 二值明暗,硬边界;不做渐变 |

**世界观 × 玩法贴合**

- 情绪:及格但需管控——高饱和 + 粗线的能量感天然偏「闹」,靠暖色板与圆润造型拉回;「休闲轻松」的上限低于 A / C。
- 玩偶感:**三方向最弱**。粗线平涂读作「卡通角色」而非「玩偶」,缝线/豆豆眼在粗线语言下退化成图形符号;玩偶身份要靠表情动作与道具叙事补,贴图细节这条路被语言本身压制。
- 积木感:最强——描边方块读数最锐,「缺一格」最清晰,破坏反馈直给。
- 帽子计分乱斗:**支柱 1/2 最优解**——粗描边堆叠剪影在 25% 缩放下存活率最高,帽王塔远距可读;§0 硬约束「多人同屏识别」同优,连带最利于支柱 4(中途进场者一眼读懂局势)。
- 死亡表现:图形化 BOOM + 星形贴合「夸张不血腥」,但通用卡通爆炸不自带玩偶语义——「棉花飞出」要刻意混进爆发帧,否则世界观在死亡时刻掉线。

**风险**:① 情绪滑向吵闹电竞感(反例板已立:不是冷色电竞);② 世界观表达三方向最弱,「动物玩偶派对」可能退化成「卡通动物派对」;③ 描边粗细在缩放下的稳定策略待验证(存档稿 §9 旧问题,仍成立)。

### 2.C 玩具质感(Tactile Toybox)

**视觉基准**

| 轴 | 基准 |
|---|---|
| 色彩 | 香草底 + 玩具糖果色(duck yellow / bubblegum / mint),饱和度中高;色不承担全部识别,材质分担 |
| 材质 | 语言本体:毛绒(短绒 + 缝线)、软胶(柔高光)、木头(木纹)、毛毡(纤维边)——2D 手绘伪立体,小面积材质高光画出「实物玩具」错觉 |
| 轮廓 | 无描边或极淡同色深边;剪影靠体积明暗,轮廓细节(绒毛边、缝线凸起)是玩偶感的载体 |
| 光影 | 三档明暗 + 材质高光点;统一「顶光」约定(见 §3 高光方向问题) |

**世界观 × 玩法贴合**

- 玩偶感:**满分且无可替代**——材质即世界观。缝线/豆豆眼/毡布是 worldview 点名的「玩偶感载体」,在 C 里是语言本体而非附加细节;「一盒玩具活了」不需要解释,看见即成立。
- 积木感:强——木纹/塑料积木块是实物玩具,worldview「地形是积木」由材质直接承载;「重新摆上桌」的重生语义因实物感而更可信。
- 情绪:高——玩具质感天然亲和,与 A 同档。
- 帽子计分乱斗:良——实体玩具帽有体积感、堆叠可信;但无描边,小尺寸剪影靠明暗,帽王塔远读弱于 B(强于 A)。
- 死亡表现:**三方向最佳**——棉花飞出、零件弹开、发条散架正是 C 特效语言的本体,表现基线由方向天然执行。

**风险**:① 8 向一致性——伪立体明暗越强,AI 多视角越难保持同一角色,三方向最大单点风险(保底产线见 §1);② painted 高光有方向性,与 8 向旋转矛盾(§3);③ 材质细节的批次漂移(绒毛密度、木纹粗细);④ **战略红旗**:ADR 0008 后果条明言「若比稿产出趋近 Party Animals 观感须回到该条重新评估」——C 是三方向最接近其软材质玩偶观感的,差异化只剩「俯视体素棋盘 + 2D」的形态组合。

## 3. 体素引擎实现含义与成本(贴图 · 调色板 · 网格生成)

**口径分两级,不发明**:

- **架构仓发布物(权威)**:基线 [`LGE-V1.4`](../architecture/LumioGameEngine_Architecture_v1.4.md) §2.1 仓库职责表——`LumioVoxelEngine` 只拥有 VoxelWorld / Chunk / Block / Revision / Mutation / Streaming / Snapshot 等**数据层**能力,渲染不在其中;客户端渲染归 `LumioClient`(`unity-adapter`,「更多 Renderer」列为后置项,v1.4 §16)。
- **本仓策划侧调研(待确认,非承诺依据)**:渲染现状为空白、Unity 工程与渲染管线均未选型([`risks-and-engine-asks.md`](risks-and-engine-asks.md) A3)。该文 §0 自述其「引擎现状」来自 2026-08-28 仓库调研,**须与引擎侧当面确认后才能作为承诺依据**,且可能与引擎侧在途工作不同步。下面第 2、3 条结论建立在这一级上,确认前按待验证处理。

由此得三条结论,先于分方向对照:

1. **引擎数据层成本三方向零差异**——block 对引擎只是类型与数据,美术方向不触碰体素契约,无引擎侧改动、无新增引擎诉求。
2. **成本差异全部落在客户端表现层与资产产线**;若 A3 的调研成立(渲染层是白地),三方向都是「新建成本」而非「返工成本」,比稿期不产生沉没成本——这是现在敢比稿的前提。**该前提待引擎侧确认**:若引擎侧已有在途渲染选型,须回到本条重算各方向的返工冲突。
3. 比稿边界已锁「场景体素、单贴图、无 PBR」(§0),三方向都在此上限内;C 对「单贴图」上限的压力最大(细节密度)。

| 维度 | A 暖软绘本 | B 明快硬描边 | C 玩具质感 |
|---|---|---|---|
| 贴图(单块) | 手绘笔触 tile;防平铺重复需每类块 2–3 变体,atlas 中等 | 平涂色块 + 烘边,单块最简、压缩最好、atlas 最小 | 材质细节最重(木纹/绒毛/高光),单块工时最高、atlas 最大 |
| 调色板治理 | 暖域窄色板,中等;「角色/地形饱和度分层」须写进色板 | 有限色板全局统一,最简单——存档稿有成套条款可复用 | 材质族 × 色系二维治理,最复杂 |
| 网格生成 | 微圆角两条路:贴图画圆角 + 标准 cube mesh(便宜,先验证);真几何倒角(网格生成器复杂度与顶点数↑,不推荐首选) | 标准 cube mesh 即可,零额外几何 | cube mesh 够用;毛毡绒边若要进块剪影需额外几何(fringe),建议放弃、绒感留给贴图 |
| 着色 / 特殊需求 | 无特殊 shader,两档明暗可烘进贴图 | 地形描边三条路:**贴图烘边**(块边 = 格边天然对齐,最便宜,首选)/ 屏幕后处理描边(依赖渲染管线选型,归 A3,暂不登记)/ inverted hull(网格翻倍,否决) | painted 高光有方向性,块面旋转复用会露馅——须立「全场顶光」约定并写进出图 prompt;角色侧「简模 → 引擎渲 8 向 sprite」把轻量 3D 环节引入主产线(ADR 0007 后果条),工具链建设是三方向唯一的产线新增项 |
| 成本合计 | 中 | **低** | 中–高(+产线复杂度) |

## 4. 统一评估维度表与推荐排序

主轴三条为 ADR 0007 锁定的评估轴;辅轴为世界观定调(ADR 0008)与本轮成本评估后补充的横向对比维度,不改变主轴优先级。

| 维度 | 权级 | A 暖软绘本 | B 明快硬描边 | C 玩具质感 | 依据 |
|---|---|---|---|---|---|
| AI 产线一致性(单张/批次/8 向) | 主轴 | ●●●○○ | ●●●●● | ●●○○○ | §1;C 有简模渲 sprite 保底但产线复杂度↑ |
| 竞技可读性(帽子塔/破坏读数/同屏识别) | 主轴 | ●●●○○ | ●●●●● | ●●●●○ | §2 各方向贴合条 |
| 情绪贴合(休闲轻松愉快) | 主轴 | ●●●●● | ●●●○○ | ●●●●● | §2;B 需暖色纪律拉回 |
| 世界观贴合(玩偶感/积木感/散架表现) | 辅 | ●●●○○ | ●●○○○ | ●●●●● | §2;ADR 0008 后新增维度 |

| 皮肤 / 长线扩展 ※ | 辅 | ●●●●○ | ●●●●○ | ●●●●● | §1 |

※ 皮肤 / 长线扩展**三方向同被阻塞**:外观向商业化依赖账号级持久化([`risks-and-engine-asks.md`](risks-and-engine-asks.md) A5),ADR 0006 / 0008 后果条均记远期,与美术方向无关。本行只比方向自身的扩展潜力,不含兑现时间。

**推荐排序(美术总监建议;方向终裁归用户,本稿不定调)**

1. **B 明快硬描边**——两条产线生死轴(AI 一致性、竞技可读性)全优、成本最低,风险全是「纪律可控型」(情绪管控 = 色板与造型条款,可写进规范执行);最大短板世界观表达可用「玩偶细节注入」缓解——缝线画进描边语言、BOOM 混棉花团、帽子画成玩具帽,是否成立列为出图验证项。
2. **C 玩具质感**——世界观贴合无可替代,**升位条件明确**:①8 向一致性小样过关(简模渲 sprite 路径实测);② 3 号同屏图观感与 Party Animals 拉开可辨识距离(ADR 0008 回评条款)。双过关则值得升首选;当前把主产线押在 AI 已知最弱项(伪立体多视角一致)上,证据不足以排第一。
3. **A 暖软绘本**——情绪最稳但两头不占:一致性不如 B、玩偶感不如 C,且帽子塔远读是三方向唯一直接顶撞支柱 1 的弱项。仅当出图后 B 情绪翻车、C 产线翻车时回头再看。

> 备注:出图后若 B 的骨架 + C 的材质符号(描边语言里的缝线/毡布细节)呈现收敛趋势,可在定调讨论中作为 B 的细化选项处理;比稿阶段不新增第四方向(ADR 0007 决策条锁定 A / B / C 三方向)。
>
> **拍板方式**:按 ADR 0007 锁定的定调流程,拍板在 §6 出图与四关筛选**之后**——三方向的关键分歧(B 的情绪、C 的 8 向、A 的帽子塔)都能被出图证伪,本稿是给那一步备好的裁决材料。若用户选择跳过出图直接拍板,该路径偏离 0007 定调流程,须在定调时**新记 ADR 取代 0007 的该条**,不得默默省略。

## 5. 竞品坐标结论

「极风格化 × 轻快」角落已拥挤(蛋仔 / 糖豆人 / Brawl Stars 均在附近)——**差异化不在情绪坐标,而在形态组合**:「俯视体素棋盘 + 2D 手绘角色」目前无人占据(最近的 Core Keeper 为纯 2D)。情绪上与头部派对游戏同区是有意为之:那是被验证的大众审美区。
