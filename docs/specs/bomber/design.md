# 体素炸弹人 · 设计稿

> **状态**：设计中
> **序位**：Lumio 首发产品（阶梯 ①）
> **上游**：[`../product-direction.md`](../product-direction.md)、[`../art-direction.md`](../art-direction.md)

## 1. 使命

**它的首要任务不是赚钱，是回答「这个画面组合到底好不好看、这套破坏玩法到底好不好玩」。**

因此设计原则是**把所有变量压到最低**：规则极简、地图小、局时短、不做养成。任何"以后可能有用"的系统一律不进首发。

## 2. 核心循环

```
移动 → 放炸弹 → 炸开方块 → 掉道具 → 变强 → 炸掉对手 → 活到最后
                                            ↓
                                    结算（15秒）→ 下一局
```

单局 2–3 分钟。房间保持不散，连续开局。

## 3. 局制规格

| 项 | 规格 |
|---|---|
| 人数 | 默认 **8 人**，上限 12 |
| 模式 | 首发只做 **个人混战（FFA）**；组队 4v4 作为第二模式 |
| 局时 | 目标 2–3 分钟，**硬上限 3 分钟** |
| 胜负 | 最后存活者胜 |
| 超时 | 150 秒触发**死亡收缩**（见 §6.4），逼出结果 |
| 平局 | 同一帧内全部死亡判平局，不加赛 |

## 4. 地图规格

**尺寸：19 × 19 格**（8 人；12 人用 23 × 23）

三类格子：

| 类型 | 说明 | 分布 |
|---|---|---|
| **硬砖** | 不可破坏 | 固定阵列：行列均为偶数索引的交叉点 |
| **软砖** | 可被炸掉，可能掉道具 | 随机填充剩余空格的 **65%** |
| **空地** | 可通行 | 其余 |

**出生点**：8 个，沿地图外圈均匀分布。每个出生点保证 **L 形 3 格安全区**（出生点 + 相邻两个方向各一格为空地），避免开局即死。

**对称性**：地图左右/上下镜像对称，保证起手公平。软砖分布可随机，但必须**镜像同步**。

## 5. 操作方案

一套玩法，两套操作。

| 动作 | PC | 移动端 |
|---|---|---|
| 移动 | WASD / 方向键 | 左侧虚拟摇杆 |
| 放炸弹 | 空格 | 右下主按钮 |
| 主动道具 | Shift | 右下副按钮 |

**移动手感**：自由八向移动（非格子对齐），但带**转角自动修正**——玩家贴着墙角走时自动吸附进通道。这是现代炸弹人手感的关键，没有它会频繁卡墙角。

**移动端布局**：两个按钮都在右下，拇指自然覆盖范围内。摇杆区域不与角色重叠（否则手指挡住自己）。

## 6. 炸弹机制（核心）

### 6.1 基础规则

| 项 | 数值 |
|---|---|
| 引爆时间 | **2.5 秒** |
| 爆炸判定持续 | 0.5 秒 |
| 爆炸形状 | 十字（上下左右四方向） |
| 初始火力 | 1 格 |
| 初始可同时放置 | 1 颗 |

### 6.2 爆炸传播

- 遇**硬砖**：立即阻断
- 遇**软砖**：摧毁该格后阻断（只吃第一层）
- 遇**玩家**：击杀
- 遇**其他炸弹**：**立即连锁引爆**

连锁引爆是这个玩法的爽点来源，必须做对——一串炸弹接连炸开的节奏感是核心记忆点。

### 6.3 道具掉落

软砖被炸开后 **30% 概率**掉落道具。掉落物停留至被拾取，可被后续爆炸摧毁。

### 6.4 死亡收缩

第 **150 秒**开始，地图从最外圈起**每 2 秒塌陷一格**，塌陷格变为硬砖并即死。螺旋向内推进，逼出结果。

## 7. 道具清单

### 增益（8 种）

| 道具 | 效果 | 上限 |
|---|---|---|
| **火力+** | 爆炸范围 +1 格 | 6 |
| **炸弹+** | 可同时放置 +1 | 6 |
| **速度+** | 移速 +0.35 格/秒 | 6.0 格/秒 |
| **踢弹** | 撞到炸弹可将其踢出 | 有/无 |
| **穿墙** | 可穿过软砖 | 有/无 |
| **遥控引爆** | 改为手动引爆（副按钮） | 有/无 |
| **护盾** | 免疫一次爆炸，消耗后消失 | 可叠 2 层 |
| **钻头** | 主动技，直接挖掉面前一格软砖 | 有/无，5 秒冷却 |

「钻头」是体素特色道具——它是**主动的、有资源成本的方块改动**，正好落在引擎为"消耗资源改方块"设计的主路径上。

### 减益（2 种，制造变数）

| 道具 | 效果 | 持续 |
|---|---|---|
| **反向操作** | 移动方向反转 | 5 秒 |
| **失控放弹** | 强制持续放炸弹 | 5 秒 |

减益道具外观与增益**明确区分**（红色调 + 不同图标），但仍会被误吃——这是设计意图，不是缺陷。

## 8. 数值框架

| 参数 | 初始 | 每级 | 上限 |
|---|---|---|---|
| 移速 | 3.5 格/秒 | +0.35 | 6.0 |
| 火力 | 1 格 | +1 | 6 |
| 炸弹数 | 1 | +1 | 6 |

**上限存在的意义**：防止滚雪球。前期领先的玩家如果无上限成长，后半局会变成单方面屠杀，破坏 8 人局的乐趣。

**一局的成长节奏**：预期玩家在 60 秒内拿到 3–4 个道具，进入"火力 3 / 炸弹 3"的舒适区，剩余时间是对抗而非发育。

## 9. 房间流程

引擎目前**没有匹配系统**，首发用**房间码**——成本最低，且天然适合开黑与自建服。

```
创建房间 → 得到 6 位房间码 → 分享 → 玩家加入
   → 房主调规则（可选）→ 房主开始 → 载入地图 → 3 秒倒计时 → 开局
   → 结算 15 秒 → 自动下一局（房间保持）
```

**房主可调规则（L0 UGC，首发即开放）**：
- 局时上限、死亡收缩起始时间
- 软砖密度、道具掉落率
- 各道具开关与权重
- 初始火力/炸弹数/移速

这是 UGC 阶梯的第一级，几乎零成本，但能立刻让服主有事可做。

## 10. 死亡与观战

死亡后进入**自由观战**，可切换视角，等待本局结束。

首发**不做**"幽灵可扔炸弹"之类的死后玩法——复杂度高、平衡难。短局（最多等 2 分钟）让死亡等待可接受。

## 11. 结算与留存

结算页展示：

- 排名、击杀数
- 放弹数、破坏方块数、拾取道具数
- **赛后回放入口**（差异化功能，见 [`../product-direction.md`](../product-direction.md) §4）
- 连胜提示

**首发不做账号进度系统**（等级、皮肤解锁、赛季）。留存靠局内爽感和房间社交，不靠养成。这符合 §1 的"把变量压到最低"。

## 12. 平衡原则

1. **不许滚雪球**——所有成长有上限，见 §8
2. **开局绝对公平**——地图镜像对称，出生点等价
3. **运气可以有，但不能决定胜负**——道具掉落是随机的，但上限机制保证落后者仍有翻盘空间
4. **死得快不如死得明白**——每次死亡玩家都要能立刻看出"我被什么炸死的"，爆炸范围必须画在地面上

## 13. 待验证项

以下是**推断，不是结论**，需在原型中实测：

| 项 | 待验证 |
|---|---|
| 引爆 2.5 秒 | 是否太长（拖沓）或太短（来不及跑） |
| 移速 3.5 格/秒 | 与 19×19 地图是否匹配 |
| 软砖 65% | 开局是否过于封闭 |
| 掉落率 30% | 成长节奏是否符合 §8 预期 |
| 8 人 / 19×19 | 是否过于拥挤或空旷 |
| 死亡收缩 150 秒 | 是否过早打断正常对局 |
| 转角自动修正 | 强度取值，卡墙角频率 |

**总验收**：拉一桌不认识这个项目的人，能不能**连着玩 20 局还想再来**。
