# 体素炸弹人 · 设计稿

> **状态**：设计中
> **序位**：Lumio 首发产品（阶梯 ①）
> **上游**：[`../product-direction.md`](../product-direction.md)、[`../worldview.md`](../worldview.md)、[`../art-style-pitch.md`](../art-style-pitch.md)

## 1. 使命

**它的首要任务不是赚钱，是回答四个问题：「这个画面组合到底好不好看、这套破坏玩法到底好不好玩、帽子塔能不能自发制造出『围攻帽王』的社交戏剧、100 人在同一张棋盘上跑不跑得动」。**

因此设计原则是**把变量压到最低**：规则极简、局时短、成长只限局内、同一套规则从 8 人到 100 人。任何"以后可能有用"的系统一律不进首发；首发内容按 §16 三阶段切片实现，每阶段可玩。

一句话规则（30 秒讲清的版本）：**「炸人抢帽子，帽子最多的赢；每人三颗心，炸一下掉一颗、连锁直接炸散；炸开据点拿装备，同样的吃两个更强；死了掉帽子掉装备，几秒复活。」**

> 100 人结构、帽子通道、装备系统与切片的定调依据见 ADR [`0011`](../../../.spec/decisions/0011-bomber-100-player-io-gear-slots.md)（取代 [`0006`](../../../.spec/decisions/0006-bomber-hat-scoring-rolling-room.md) 的人数、帽子发行与死亡代价条款，重申其余）；血量取代一击即死的定调依据见 ADR [`0012`](../../../.spec/decisions/0012-bomber-hearts-replace-one-hit-kill.md)。

## 2. 核心循环

```
        发育：炸软砖 / 攻据点 → 掉糖果 / 装备箱 / 狂暴糖 → 变强（合成升级 / 替换）
          ↑                                    ↓
   重生（数秒） ← 被炸死·帽子全散·装备半掉 ← 炸掉对手·铸 1 顶帽·捡他的帽子和装备
          ↑                                    ↓
          └── 帽子垒高 → 帽王亮起光柱 → 被分区乃至全场围攻 ──┘

   会话：局计时结束 → 结算（15 秒，Top-10）→ 自动下一局（房间连轴转，随时进出）
```

帽子经济两条通道：**击杀 = 铸造**（每次击杀凭空发 1 顶到击杀者头顶）、**击杀 = 转移**（死者帽子散落可拾）。装备经济也是两条：**装备箱 = 发行**、**死亡掉落 = 转移**。谁都能看见谁最富——帽子塔就长在头顶上，帽王头顶还有光柱。

## 3. 产品支柱

六条可证伪的支柱，用来否掉未来的具体提案：

| # | 支柱 | 这意味着 | 这不意味着 |
|---|---|---|---|
| 1 | **帽子塔是局部计分板，Top-10 是全局摘要** | 屏幕内谁最富一眼可见；全局只给 Top-10 侧栏与帽王光柱；否掉把主计分藏进 UI 面板、否掉全员帽数小地图 | 没有任何 UI（计时、Top-10、结算仍有） |
| 2 | **领先自带风险，制衡靠玩家不靠数值** | 帽王更显眼、更被觊觎，围攻是自发行为；否掉「帽子多移速慢」类数值惩罚，也否掉给帽王的数值奖励 | 系统不为帽王的可见性做任何事（光柱正是为可见性做的） |
| 3 | **死亡是节奏不是惩罚** | 死亡代价只有两项：帽子全散、每件装备 50% 落地；否掉长重生 CD、死亡扣分、死亡清糖果、出局观战 | 死亡无代价（帽子和装备就是代价） |
| 4 | **随时能进，进来就懂** | 中途加入是一等公民，新系统不得提高进场理解成本；任何拾取走过去就生效、无菜单；否掉第二计分资源、开局仪式流程 | 玩法没有深度（装备搭配与地形博弈仍在） |
| 5 | **一局是一场围绕帽王的戏剧** | 发行→积累→帽王→围攻→崩塌哄抢→新王，在分区内多次轮回，光柱把分区戏剧升级为全场戏剧；否掉让帽子或装备流转停滞的设计（如绑定不掉落） | 固定剧本或强制平均分配戏份 |
| 6 | **同一套规则从 8 人到 100 人** | 数值不随人数变，只有地图档位随人数缩放；否掉只在大人数下才成立的机制（如 ≥50 人才触发的事件） | 8 人房与 100 人房体验完全一样（密度与戏剧规模自然不同） |

### 3.1 爽感时刻

玩法必须稳定交付的「爽」，每条挂钩支柱并标成本类别：**表现层** = 客户端本地表现（零服务器成本、不复制）；**服务器事件** = 一条广播事件；**内容** = GAS 数据或美术资产。

| 时刻 | 触发 | 表现 | 支柱 | 成本 |
|---|---|---|---|---|
| 连锁 | 同一爆炸链 ≥ 3 颗 | 「×N 连锁」弹字、屏幕震动随 N 增强、50–80ms 定帧；3 连锁 = 秒杀（§12） | 5 | 表现层 |
| 多杀 | 同一爆炸链击杀 ≥ 2 | 「双杀 / 三杀 / 一锅端（≥4）」弹字 + 音效 | 5 | 服务器事件 + 表现层 |
| 收割 | 一次连续捡起 ≥ 5 顶帽 | 帽塔快速叠高动画、连拾音效音高递增 | 1 / 5 | 表现层 |
| 合成 | 同技能合成升级 | 装备闪光；**每个 Lv3 必须有一眼可见的形态变化** | 4 | 内容 |
| 加冕 | 成为帽王 | 光柱亮起 + 「你是帽王」横幅 + 音乐层 | 1 / 2 | 服务器事件 + 表现层 |
| 倒台 | 帽王死亡 | 全场横幅「X 的 N 顶帽子散落了！」→ 踩踏式哄抢 | 5 | 服务器事件 |
| 开箱 | 据点宝箱打空 | 战利品喷泉式散落；大据点开启全场横幅 | 4 / 5 | 服务器事件 + 表现层 |
| 狂暴 | 吃到狂暴糖 | 全身红光 + 加速音乐 + 6 秒无限放弹（§8.5） | 5 | 内容 |
| 逆袭 | 0 帽玩家击杀帽王后成为帽王 | 「逆袭！」横幅 | 2 / 5 | 表现层 |
| 拆迁 | 单次爆炸链破坏 ≥ 12 格 | 碎块飞溅加强 + 「拆迁 ×N」弹字 | — | 表现层 |
| 绝境 | 1 心逃生后捡到血包 | 心跳音停止 + 回血音效 + 玩偶缝合动画 | 3 | 表现层 |

全场横幅只播大事件（加冕、倒台、大据点预告 / 开启），其余弹字只对本人显示——100 人下横幅刷屏会毁掉可读性（推断待验证）。

## 4. 局制规格

| 项 | 规格 |
|---|---|
| 人数 | **8–100 人弹性**，随中途进出浮动；官方默认房上限 **100**（引用：架构 v1.4 §12「100 人是第一阶段目标负载」；实测负载后是否留余量下调，待验证） |
| 模式 | 首发只做**帽子乱斗（FFA 计分）**；团队帽子赛作为第二模式候选（兼作模式数据格式的试金石，见 [`../ugc-ladder.md`](../ugc-ladder.md) §0） |
| 局时 | **5–10 分钟**滚动局；100 人倾向先测 8 分钟（推断待验证） |
| 胜负 | 计时结束，**头顶帽子最多者胜**，Top-10 上榜 |
| 平局 | 帽数并列即并列同胜，不加赛 |
| 中途进出 | 任意时刻可加入（局末锁入期除外，见 §11）；中途退出者帽子与装备当场散落回流 |

## 5. 地图规格：人数-地图联动

目标密度约 **26–30 可通行格 / 人**（推断待验证）。局开始时按在场人数（加预期加入量）选档，局中不变；房主可用 L0 规则锁定档位。

| 在场人数 | 棋盘 | 分区 | 每区约人数 |
|---|---|---|---|
| ≤12 | 19×19 | 无 | ≤12 |
| 13–30 | 31×31 | 2×2 | 3–8 |
| 31–60 | 45×45 | 3×3 | 3–7 |
| 61–100 | 61×61 | 4×4 | 4–6 |

（档位与尺寸均为推断待验证）

三类格子（分区内与旧稿相同）：

| 类型 | 说明 | 分布 |
|---|---|---|
| **硬砖** | 不可破坏 | 固定阵列：行列均为偶数索引的交叉点；另构成分区墙 |
| **软砖** | 可被炸掉，可能掉糖果 / 减益 / 装备箱 | 随机填充剩余空格的 **65%** |
| **空地** | 可通行 | 其余 |
| **据点宝箱** | 有 HP 的实体格：每颗炸弹的爆炸触及即 −1 HP（与火力无关），并阻断传播 | 每分区中心 1 个小据点、棋盘中心 1 个大据点（§8.6） |

**分区墙**：硬砖墙把棋盘切成分区，每段墙中点留 **3 格缺口**（推断待验证）。分区是「经典密度的小竞技场」——100 人的遭遇仍是 4–8 人规模，帽王戏剧先在分区内轮回。

**据点地形**（炸哪里才能变强，规则见 §8.6）：每个分区中心一个**小据点**、棋盘中心一个**大据点**。据点是硬砖围成的「围院」：小据点 3×3 院、对角两个入口；大据点 5×5 院、四边中点四个入口；院内无软砖、地面硬砖，中央一格是有 HP 的宝箱。围院是故意的死亡陷阱：硬墙不吸收爆炸、入口是卡点，在院里放弹等于把自己和对手一起关进火里。院内没有软砖，人群最密处不产生方块写入（引用：[`../risks-and-engine-asks.md`](../risks-and-engine-asks.md) A8）。≤12 人档（19×19）无分区，只有大据点（推断待验证）。

**象限地色**：四个象限用不同地面材质区分（材质目录加 4 行），给 100 人棋盘一个不看小地图也能说出「我在哪、去哪」的方位语言（推断待验证）。

**出生 / 重生点**：**动态选点**取代固定 8 点——选当前人数最少的分区，在其中随机取可通行格，距任一玩家与炸弹 **≥ 6 格**（推断待验证），并保证 **L 形 3 格安全区**（该点 + 相邻两方向各一格为空地；不满足则清掉 ≤ 2 格软砖，属微量方块写入）。

**对称性**：棋盘四象限镜像对称，分区彼此等价；软砖分布可随机，但必须镜像同步。

**软砖再生**：滚动局会把软砖耗尽，导致后半局无方块可炸、无掉落来源。软砖按固定间隔在**无人区域**批量再生，直至恢复目标密度（速率待验证）。再生是低频批量写入，量级远低于爆炸破坏。

### 5.1 场景材质：什么能炸、炸了变成什么

材质是本仓拥有的 MaterialId 目录里的行（引用：[`../engineering/mvp-placevoxel-content-spec.md`](../engineering/mvp-placevoxel-content-spec.md) §6.2），每种材质一行数据、五个字段：可破坏、阻断爆炸、破坏后残留、掉落、地面效果。Voxel 引擎不解释含义，全部行为在玩法层的爆炸函数与 GAS Effect 里消费。首发同屏可见的材质不超过 6 种，每种轮廓与色相一眼可辨（支柱 4）。

| 材质 | 世界观 | 可破坏 | 阻断爆炸 | 破坏后 | 掉落 | 阶段 |
|---|---|---|---|---|---|---|
| **积木** | 软砖主体，彩色积木 | 是（1 次爆炸） | 是（吃第一层） | 露出地面，碎块飞溅 | 30% 糖果 / 减益 / 装备箱 | 1 |
| **铁皮** | 硬砖、分区墙、据点围院 | 否 | 是 | — | — | 1 |
| **木箱** | 上锁的小木箱 | 是（1 次爆炸或钻头） | 是 | 箱子裂开 | **必掉** 1 个装备箱或糖果 | 1 |
| **水盆** | 桌面上的水盆 / 护城河（地面，非砖） | 否 | **是**（爆炸到水边停） | — | — | 1 |
| **木头** | 木头玩具积木 | 是（1 次爆炸） | 是 | 露出地面并**留火 1.5 秒**（区域 Effect，不改方块），随后焦痕贴花 | 同积木 | 2 |
| **鞭炮** | 一串鞭炮 | 是（任何爆炸触及） | — | **自身引爆**：火力 2 的十字爆炸，计入爆炸链 | 无 | 2 |
| **冰面** | 冻住的水盆 | 否（会融化） | 否 | 5 秒后化回水 | — | 3 候选 |

（配比、时长均推断待验证）

**地面效果**（走在上面）：水盆——移速 −30%、**不能放炸弹**（放下即熄灭，炸弹消失）、进入即解除燃烧；火地（木头燃烧中 / 火焰弹留火）——每秒 −1 心（§12）；冰面——惯性打滑。地面是「破坏后露出的东西」，象限地色也是地面材质。

**破坏后的样子**：一律「露出地面 + 材质对应的残留」——积木碎块飞溅、木头留火后焦痕、鞭炮焦痕、木箱裂开。残留是贴花与粒子（表现层），不是方块；软砖再生按原配比补回积木 / 木头 / 木箱 / 鞭炮（推断待验证）。

### 5.2 技能 × 场景交互

交互只有两类合法形态：**读材质改行为**（零写入）与**区域 Effect**（零写入）；会写方块的临时交互只有「冰冻水面」，列为阶段 3 候选（引用：[`../risks-and-engine-asks.md`](../risks-and-engine-asks.md) A8）。

| 技能 | × 材质 | 结果 | 阶段 |
|---|---|---|---|
| 任何炸弹 | 水盆 | 放在水里立即熄灭；爆炸到水边停 | 1 |
| 踢弹 | 水盆 | 把炸弹踢进水里 = 拆弹（防守核心动作） | 2 |
| 分裂弹 | 水盆 | 子弹落水熄灭 | 2 |
| 火焰弹 | 木头 | 留火时长翻倍 | 2 |
| 火焰弹 | 水盆 | 无留火 | 2 |
| 冰冻弹 | 火地 | 灭火 | 2 |
| 钻头 | 木箱 | 不放弹也能开箱（无声拾荒） | 2 |
| 筑墙 | 任意地面（水盆除外） | 放一块积木 | 2 |
| 穿透弹 | 木头 / 积木 | 全线摧毁；木头段全部留火 | 2 |
| 任何爆炸 | 鞭炮 | 引爆，计入连锁 | 2 |
| 冰冻弹 | 水盆 | 结冰 5 秒：可走、可放弹、打滑（临时方块写入） | 3 候选 |

### 5.3 场景可玩性需求（给地图生成器的明确要求）

每张棋盘必须满足以下断言，生成器不满足即重生成（数值推断待验证）：

1. **每个分区**：1 个据点（§8.6）、1 处水盆（3–6 格池塘或据点半圈护城河）、木箱 3–5 个、鞭炮簇 1–2 处（3–4 格相邻）、木头区 1 片（8–12 格）；其余软砖为积木。
2. **水盆 ≤ 5% 格子**，只作池塘与护城河，**不得封死分区缺口或出生安全区**；水边至少留 1 格陆路绕行。
3. **每个可通行格 3 秒内可到达一处掩体**（铁皮硬砖阵列保证），软砖全部炸光后仍成立。
4. **无死角**：软砖全炸光后任意两可通行格连通；出生 L 形安全区不含水盆与鞭炮。
5. **对称与等价**：四象限镜像；据点、水盆、鞭炮簇镜像同步。
6. **可读性**：同屏可见材质 ≤ 6 种；鞭炮与木箱必须在俯视下与积木一眼区分（进 B1）。
7. **地标**：每象限用象限地色 + 1 个铁皮地标轮廓（生成器模板，如动物剪影）作方位语言。

## 6. 操作方案

一套玩法，两套操作。

| 动作 | PC | 移动端 |
|---|---|---|
| 移动 | WASD / 方向键 | 左侧虚拟摇杆 |
| 放炸弹 | 空格 | 右下主按钮 |
| 主动槽技能 | Shift | 右下副按钮 |

**移动手感**：自由八向移动（非格子对齐），但带**转角自动修正**——玩家贴着墙角走时自动吸附进通道。这是现代炸弹人手感的关键，没有它会频繁卡墙角。

**移动端布局**：两个按钮都在右下，拇指自然覆盖范围内。摇杆区域不与角色重叠（否则手指挡住自己）。

## 7. 炸弹机制（核心）

### 7.1 基础规则

| 项 | 数值 |
|---|---|
| 引爆时间 | **2.5 秒** |
| 爆炸判定持续 | 0.5 秒 |
| 爆炸形状 | 十字（上下左右四方向）；炸弹槽装备可改形态（§8.4） |
| 初始火力 | 1 格 |
| 初始可同时放置 | 1 颗 |
| 对玩家伤害 | 每颗炸弹 −1 心（§12），与火力无关 |

### 7.2 爆炸传播

- 遇**硬砖**：立即阻断
- 遇**软砖**：摧毁该格后阻断（只吃第一层；穿透弹例外，见 §8.4）
- 遇**玩家**：−1 心（§12）；冰冻弹例外：冻结不扣心
- 遇**水盆**：阻断（§5.1）
- 遇**鞭炮**：引爆，计入连锁（§5.1）
- 遇**其他炸弹**：**立即连锁引爆**

连锁引爆是这个玩法的爽点来源，必须做对——一串炸弹接连炸开的节奏感是核心记忆点。

### 7.3 炸弹形态

炸弹槽决定炸弹形态，无装备时为标准弹。所有形态共用 7.1 / 7.2 的传播规则，只改「爆炸形状函数 + 参数」；形态清单与等级见 §8.4。

### 7.4 掉落

软砖被炸开后 **30% 概率**产生掉落物——糖果、减益或**装备箱**（池内权重见 §8.2）。木箱**必掉**（§5.1）。狂暴糖默认不进软砖池，只出自大据点（§8.6）。掉落物停留至被拾取，可被后续爆炸摧毁。

**方块写入封顶**（引用：约束 5，[`../risks-and-engine-asks.md`](../risks-and-engine-asks.md) A8）：单次爆炸最多摧毁 24 格（火力上限 6 × 4 向）；穿透 L3 上限 = 火力全线；100 人满负载估算每秒 100–300 格破坏（推断，阶段 1 压测实测）。

## 8. 装备与技能

### 8.1 三槽模型

| 槽 | 管什么 | 触发 |
|---|---|---|
| **炸弹槽** | 炸弹形态 | 放炸弹时生效 |
| **主动槽** | 一个有冷却的主动技能 | Shift / 副按钮 |
| **被动槽** | 一个常驻效果 | 自动 |

每槽最多 1 个技能，等级 1–3。无装备时：标准弹、无主动、无被动。

### 8.2 来源

| 通道 | 规则 | 性质 |
|---|---|---|
| **装备箱** | 软砖掉落池的一种掉落物，开出随机 Lv1 技能（池内权重待验证） | 发行 |
| **木箱** | 场景里可见的小木箱，炸开或钻开必掉 1 个装备箱或糖果（§5.1） | 发行 + 微目标 |
| **死亡掉落** | 死者每件装备 **50%** 落地，带等级（推断待验证） | 转移 |
| **小据点** | 每分区中心的围院宝箱（HP 5），打空后战利品散落院内：装备箱 ×2 + 糖果 ×3 + 血包 ×1（§8.6） | 发行 + 分区目标 |
| **大据点** | 棋盘中心的围院宝箱（HP 15），打空后散落：装备箱 ×3（其中 1 件直出 Lv2）+ 狂暴糖 ×1 + 糖果 ×5 + 血包 ×2（§8.6） | 发行 + 全场节奏器 |

### 8.3 拾取规则（走过即生效，无菜单）

| 情形 | 结果 |
|---|---|
| 该槽为空 | 装备 |
| 同技能 | 等级 +1（合成）；已满级（3）则不拾取，物品留地 |
| 异技能，拾取物等级 ≥ 已装备等级 | 替换，旧装备销毁（「旧装备落地」进待验证） |
| 异技能，拾取物等级 < 已装备等级 | 不拾取，物品留地 |

效果：地面装备箱开出的全是 Lv1，合成过的玩家不会被路边 Lv1 换掉；只有别人掉落的高级装备能顶替你——「顶替」本身就是击杀的战利品。

### 8.4 技能池 v0

★ = 阶段 2 首批（每类 3 个）；L1 → L3 数值全为**推断待验证**。

| 槽 | 技能 | 效果 | L1 / L2 / L3 |
|---|---|---|---|
| 炸弹 | ★ 标准弹 | 十字，范围 = 火力 | 范围 +0 / +1 / +2 |
| 炸弹 | ★ 火焰弹 | 直击 −1 心并附加燃烧（每秒 −1 心）；爆后留火，踩入也点燃 | 燃烧 1s / 2s / 3s；留火 1.5s / 2.5s / 3.5s |
| 炸弹 | ★ 冰冻弹 | 不扣心，范围内玩家冻结（可被炸） | 1s / 1.5s / 2s |
| 炸弹 | 穿透弹 | 火焰穿过软砖 | 多穿 1 层 / 2 层 / 全线（方块写入 ↑，受 A8 约束） |
| 炸弹 | 分裂弹 | 引爆时四端各生 1 子弹（0.5s 后炸） | 子弹火力 1 / 2 / 子弹再分裂一次 |
| 主动 | ★ 冲刺 | 前方 3 格冲刺，可越炸弹 | CD 8s / 6s / 4s |
| 主动 | ★ 筑墙 | 面前放软砖（复用 `PlaceVoxelAbility`） | 1 格 / 2 格 / 3 格横排；CD 5s / 4s / 3s |
| 主动 | ★ 泡泡 | 无敌并解除燃烧，期间不能放弹 | 1.5s / 2s / 2.5s；CD 15s / 12s / 10s |
| 主动 | 钻头 | 挖面前 1 格软砖（复用 `DigVoxelAbility`） | CD 3s / 2s / 1s |
| 主动 | 磁铁 | 3 秒内吸附半径内掉落物（帽 + 装备） | 半径 2 / 3 / 4 格；CD 12s |
| 被动 | ★ 厚棉花 | 心上限提高 | 上限 +1 / +2 / +2 且脱战 10 秒回 1 心 |
| 被动 | ★ 幽灵 | 穿软砖 | 穿软砖 / +移速 0.35 / 可穿炸弹 |
| 被动 | ★ 踢弹 | 撞炸弹踢出 | 3 格 / 5 格 / 直到障碍 |
| 被动 | 长手 | 拾取半径 + | +0.5 / +1 / +1.5 格 |
| 被动 | 遗爆 | 死亡原地留标准弹（归属死者，可铸帽） | 火力 1 / 火力 2 / 2 颗 |

**实现口径**：每个技能 = GAS Ability（激活）+ Effect（时长 / 属性修正）+ Tag；炸弹形态 = 一个爆炸形状函数 + 参数；「筑墙 / 钻头」直接复用 MVP 的两个 Ability（引用：[`../engineering/mvp-placevoxel-content-spec.md`](../engineering/mvp-placevoxel-content-spec.md) §2）。零新框架，技能池即数据，兼作 L2 UGC 表达力的试金石。

### 8.5 糖果与减益（无槽）

| 糖果 | 效果 | 上限 |
|---|---|---|
| **火力+** | 爆炸范围 +1 格 | 6 |
| **炸弹+** | 可同时放置 +1 | 6 |
| **速度+** | 移速 +0.35 格/秒 | 6.0 格/秒 |
| **血包** | 回 1 心（§12）；满心不拾取留地 | 心上限 |

糖果不占槽、死亡不清（支柱 3）。

**狂暴糖（稀有）**：只出自大据点（§8.6；是否以极低权重进软砖池待验证）。吃到即回满心并进入 **6 秒狂暴**：火力满（6）、放弹不计炸弹数上限、引爆时间缩为 1.0 秒、**免疫自己的炸弹**；**不免疫他人**，被炸死照常掉帽掉装备（全为推断待验证）。外观全身红光 + 音乐加速，全场可见。它是把「去炸大据点」和「爽」绑在一起的那颗糖：最强的 6 秒只能靠抢来。

| 减益 | 效果 | 持续 |
|---|---|---|
| **反向操作** | 移动方向反转 | 5 秒 |
| **失控放弹** | 强制持续放炸弹 | 5 秒 |

减益外观与糖果 / 装备箱**明确区分**（红色调 + 不同图标），但仍会被误吃——这是设计意图，不是缺陷。

**旧稿道具去向**：踢弹 → 被动；穿墙 → 被动「幽灵」；护盾 → 被动「厚棉花」；钻头 → 主动；遥控引爆 → 首发不做（多一套输入，去留待验证）。

> 帽子**不是装备**：帽子没有任何数值效果、不占槽，规格见 §9。

### 8.6 据点：炸哪里才能变强

据点回答 100 人棋盘上「我该去哪」——它是固定地点的目标、装备的主要发行口、也是引导人群聚集的绞肉机。地形见 §5「据点地形」。

| 项 | 小据点（每分区中心） | 大据点（棋盘中心） |
|---|---|---|
| 宝箱 HP | 5 | 15 |
| 伤害规则 | 每颗炸弹的爆炸触及宝箱格即 −1 HP，与火力无关；连锁 3 颗 = 3 伤；宝箱阻断爆炸传播 | 同左 |
| HP 显示 | 宝箱头顶血条，院外可见 | 同左 + 全图光柱（与帽王光柱颜色区分） |
| 开启 | HP 归零 → 战利品**散落院内**，谁捡归谁，无最后一击归属 | 同左 + 全场横幅 |
| 战利品 | 装备箱 ×2（Lv1）+ 糖果 ×3 + 血包 ×1 | 装备箱 ×3（其中 1 件直出 Lv2）+ 狂暴糖 ×1 + 糖果 ×5 + 血包 ×2 |
| 刷新 | 开启后 90 秒 | 开启后 150 秒；刷新前 15 秒全场预告 + 光柱亮起 |
| 人数缩放 | 数值不变（支柱 6），只有据点数随分区数缩放 | 全档位恒 1 个 |

（全部数值推断待验证）

- **不做最后一击归属**：战利品散落、开放哄抢——不需要伤害归属逻辑，且院内哄抢就是支柱 5 的「崩塌哄抢」。
- **不出帽子**：帽子只来自击杀（ADR 0011）；据点聚人 → 击杀发生在据点 → 帽子照样从那里来。
- **实现口径**：宝箱 = 一个带 Health 属性的实体（GAS Attribute），爆炸对其施加 −1 的 Effect；围院 = 地图生成器模板；光柱与横幅复用帽王光柱与全场事件通道。零新框架。

## 9. 帽子系统（核心）

### 9.1 获取：铸造与转移

| 通道 | 规则 | 性质 |
|---|---|---|
| **击杀铸造** | 击杀 +1 顶铸到击杀者头顶；归属 = 打掉最后一颗心的炸弹主人，燃烧致死归火焰弹主人；自杀不铸（推断待验证） | 发行——解决 100 人下大量击杀零帽新人的经济停滞 |
| **击杀散落** | 死者帽子**全部**散落在死亡点周围可通行格（全掉 vs 半掉待验证，首发倾向全掉——戏剧最大化） | 转移——帽子在玩家间流动 |
| **退出回流** | 中途退出者帽子当场散落 | 守恒——帽子不随人离场蒸发 |

宝箱不再出帽：旧稿「帽子宝箱」改为装备箱（§8.2）。

### 9.2 堆叠与通胀控制

帽子在头顶**物理堆叠**，塔高即分数，无单人数值上限——制衡靠散落与围攻，不靠封顶。

回收阀只保留一个：**散落帽 20 秒无人拾取即消失**（推断待验证）。「发行封顶」取消——击杀铸造随人数与击杀率自然缩放；若原型出现通胀再议。

### 9.3 帽王可见性

- **屏幕内帽塔 = 局部计分板**（支柱 1）：最高的塔自然最显眼。
- **Top-10 侧栏**：名字 + 帽数（Top-10 vs Top-5 待验证）。
- **帽王光柱**：第一名且 ≥ N 顶（N 待验证）时头顶竖起光柱，全图可见其方向；玩具世界口径「聚光灯」，表现归美术。
- 屏幕边缘帽王方向箭头（候选，待验证）。
- 据点光柱与帽王光柱必须颜色区分（大据点预告用，§8.6）。

帽子**不随技能等级增加**；技能强度用装备自身外观表达，保证帽子塔只回答「谁在赢」。

### 9.4 死亡结算

心归零即死（§12）；死亡时帽子全散、每件装备 50% 落地、**糖果不清**——死亡代价只有两项（支柱 3），滚雪球已由糖果上限与装备等级上限拦截（§10）。

### 9.5 帽子明确不做的

- **无数值加成**：帽子不加移速 / 火力 / 防御——纯计分物（支柱 2 双向：帽王不吃惩罚也不吃奖励）；
- **不随技能等级增加**：帽子只代表击杀与掠夺；
- **无种类差异**：首发只有一种帽子；帽子外观 / 皮肤 / 收藏属账号级持久化，被引擎前置（[`../risks-and-engine-asks.md`](../risks-and-engine-asks.md) A5）阻塞，记远期不进首发。

## 10. 数值框架

| 参数 | 初始 | 每级 | 上限 |
|---|---|---|---|
| 移速 | 3.5 格/秒 | +0.35 | 6.0 |
| 火力 | 1 格 | +1 | 6 |
| 炸弹数 | 1 | +1 | 6 |
| 装备等级（每槽） | 无 | +1（同技能合成） | 3 |

**上限存在的意义**：防止滚雪球。前期领先的玩家如果无上限成长，后半局会变成单方面屠杀，破坏多人局的乐趣。

**成长节奏**：预期玩家在 60 秒内拿到 3–4 个糖果进入"火力 3 / 炸弹 3"的舒适区，并开出 1–2 件 Lv1 装备；一局内达成 1 件 Lv3 可达但不必然（推断待验证）。滚动局下死亡不清糖果，全场会趋于满配均势——中后期的差距只剩帽子、装备搭配与操作。

## 11. 会话与房间

**滚动房间模型**：房间常驻，一局接一局连轴转；玩家随时进、随时走，服务器可同时开多个房间。

```
快速加入 / 房间码 → 进入房间（任意时刻）
   → 局中：立即入场（局末锁入期改为观战等下一局）
   → 局计时结束 → 结算 15 秒 → 自动下一局（房间保持，按人数重选地图档位）→ ……
```

**双入口**：

| 入口 | 定位 | 依赖 |
|---|---|---|
| **快速加入** | 默认入口：把玩家丢进一个未满的官方参数房间 | 引擎侧「房间目录 + 快速加入」轻量能力——**已登记为 ① 的入口依赖**（[`../risks-and-engine-asks.md`](../risks-and-engine-asks.md) A6）；不是技能 / 段位匹配 |
| **房间码** | 保底入口 + 好友开黑 + 自建服 / 自定义规则房 | 无，首发可用 |

**快速加入只进官方默认参数的房间**；房主改过规则的房间走房间码或房间列表——避免新玩家被丢进认不出的规则变体（推断待验证）。

**局末锁入**：最后 N 秒（待验证，约 30）不再放新人入局，避免进场即结算；锁入期玩家观战等下一局。

**房主可调规则（L0 UGC，首发即开放）**：
- 局时、房间人数上限、地图档位锁定与分区开关
- 软砖密度、再生速率
- 掉落率、糖果 / 减益 / 装备箱的池内权重、技能池各技能开关与权重
- 装备掉落率、击杀铸帽数、死亡掉帽比例、重生秒数
- 据点开关、宝箱 HP 与刷新周期、狂暴糖开关
- 心数上限、血包权重、燃烧开关
- 初始火力 / 炸弹数 / 移速

这是 UGC 阶梯的第一级，几乎零成本，但能立刻让服主有事可做。

## 12. 血量、死亡、重生与观战

**血量**（定调依据 ADR 0012；全部数值推断待验证）：

| 项 | 规则 |
|---|---|
| 心数 | 每人 **3 颗心**（整数，引用 config IntegerOnly 纪律）；重生满心 |
| 爆炸伤害 | 每颗炸弹的爆炸触及 −1 心，与火力无关；同一爆炸链每颗炸弹各算一次，同一颗炸弹对同一人只算一次——**单发削血，连锁秒杀** |
| 燃烧 | 火焰弹直击后附加：每秒 −1 心，L1 1s / L2 2s / L3 3s；泡泡或血包解除；燃烧中玩偶冒烟、倒计时可见 |
| 血包 | 糖果池与据点战利品；回 1 心，满心不拾取留地 |
| 回血 | 只有血包与厚棉花 L3 的脱战回血；不做自然回血——残血必须去找血包 |
| 残血表现 | 本人：1 心时屏幕边缘红晕 + 心跳音；他人：玩偶破损三档（完好 / 露线 / 露棉花），首版可用受击后 3 秒显示的小血条代替（进 B1） |

血量要制造的是「残血逃生 / 追杀残血」的张力：被炸一下不死，但一心残血在 100 人棋盘上跑向最近的血包或据点，是全局最紧张的 10 秒。

- **死亡**：心归零即死 + 帽子全散 + 每件装备 50% 落地。死亡瞬间的帽子与装备飞散要做足表现——它是全场哄抢的发令枪（表现细节归美术，世界观基线见 [`../worldview.md`](../worldview.md) §2）。
- **重生**：数秒后（3–5 秒待验证）在动态出生点满心复活（§5）；带短暂**重生保护**（1–2 秒无敌 + 闪烁，放弹即解除，时长待验证）。
- **观战**：本模式没有死亡观战等待（支柱 3）；观战只存在于局末锁入期与结算间歇。

## 13. 结算与留存

结算页展示：

- **Top-10 榜**、本人名次与「击败了 X% 的玩家」、**帽王时长**（本局持有最高塔的累计时间）
- 击杀数、放弹数、破坏方块数、拾取数、本局最高装备
- **赛后回放入口**（差异化功能，见 [`../product-direction.md`](../product-direction.md) §4）
- 连胜提示

**首发不做账号进度系统**（等级、皮肤解锁、赛季）。留存靠局内爽感和房间社交，不靠养成。帽子皮肤 / 装备外观类养成同此，且另被 A5 阻塞（见 §9.5）。

## 14. 平衡原则

1. **不许滚雪球**——糖果与装备等级有上限（§10），帽子零数值加成（§9.5）
2. **重生绝对公平**——棋盘四象限对称，动态出生点远离威胁
3. **运气可以有，但不能决定胜负**——掉落是随机的，但帽子只能靠杀和抢：财富分配由冲突决定，不由掉落决定
4. **死得快不如死得明白**——每次死亡玩家都要能立刻看出"我被什么炸死的"，爆炸范围与留火必须画在地面上；每次掉心同理，燃烧要有倒计时
5. **装备是流动的不是终身的**——任何等级都可能落地易主；否掉绑定 / 不可掉落装备
6. **同一套规则从 8 人到 100 人**——数值不随人数改变，只有地图随人数缩放
7. **爆点可以有，但必须有时限、可反制、来源可争夺**——狂暴糖 6 秒、不免疫他人、只出自大据点；否掉常驻或不可反制的强化

## 16. 实现切片（三阶段）

设计一次写全，实现分步；每阶段可玩、纯数据叠加。

|---|---|---|---|
| **1 · 100 人底盘** | 人数-地图联动生成 + 分区墙 + 材质（积木 / 铁皮 / 木箱 / 水盆）+ 动态出生 + 标准弹 + 三心血量 + 血包 + 三糖果 + 两减益 + 帽子（击杀铸 / 散落 / 超时）+ 据点（战利品 = 糖果 + 狂暴糖）+ Top-10 + 帽王光柱 + 爽感横幅（连锁 / 多杀 / 加冕 / 倒台 / 开箱）+ 滚动局 + 结算 | 跑得动吗；100 人在一起好玩吗；帽王戏剧在分区里转不转 | 100 bot 压测（复用 `integration/entity-chat/` 的 Bot01–100 骨架，产出架构 §12 要求的 100 人 Workload 基线）+ 8 人小房手测 |
