# Art Prompt(AI 出图提示词)

把美术方向系统地翻译成 AI 出图 prompt。方向权威在 [art-director](../art-director/SKILL.md),规范基准在 `docs/specs/art-direction.md`(落点定义见 [art-bible](../art-bible/SKILL.md))——本技能只做翻译,不做定调。

## 何时使用

- 需要为概念探索、mood board、参考图、资产底稿生成出图 prompt。
- art-director 提案阶段需要候选风格参考图(探索模式)。

## 操作步骤

1. **读基准。** 规范已建 → 读风格锚、色彩系统、禁区。未建 → **探索模式**:与用户确认本次风格假设,所有产出显式标注「风格未锁定,按假设 X 输出,仅探索」,并把假设登记为待决策项抛回 [art-director](../art-director/SKILL.md)。
2. **明确意图。** 三要素:目的(风格探索 / 概念参考 / 资产底稿)、美术域(分类见 [art-director](../art-director/SKILL.md) 快速参考)、目标工具。两种模式显式区分:**定调期发散**(高风格化、多方向、允许意外)vs **生产期收敛**(锁风格锚、锁参数、只变主体)。
3. **构造 prompt(8 段解剖)。** 中文沟通意图,英文输出 prompt:①主体(具体名词短语,不写 "a character",写 "young herbalist girl, twin braids, oversized satchel")②**风格锚**(15-25 词固化短语,来自规范、全项目复用、版本化管理,禁止即兴改写——这是风格一致性的核心资产)③媒介词(game concept art / flat UI icon / isometric environment render)④构图镜头(图标类必须正交平视)⑤光影(按域固定)⑥色板注入(HEX + limited palette)⑦负向排除(photo-realistic, text, watermark + 规范禁区直译)⑧参数层(画幅 / 风格化强度 / seed,按工具映射)。风格参考与角色一致性分开管理(风格一致 ≠ IP 一致)。
4. **成组交付与筛选。** 每需求 2-3 个变体并说明差异;seed 复用做同主体变体,同批锁同参;逐条标注对应规范条款或「探索假设」。产出图过**筛选四关**:风格关(对照支柱,可证伪判断)→ 结构关(手部 / 对称装饰错位 / 透视混乱等 AI 高发硬伤)→ 落地关(可拆件 / 可切九宫 / 缩到实机可读)→ 合规关(不复刻具体 IP;AI 图默认只作概念/参考/垫图,直接进包须人工重制或过 [art-review](../art-review/SKILL.md) 全条款,并遵守商店对 AI 内容的申报要求)。

## 快速参考

### Prompt 骨架(填空模板)

```text
[主体:具体名词短语], [风格锚:项目固化短语(带版本)], [媒介词],
[构图镜头], [光影], [色板:HEX + limited palette]
负向: photo-realistic, text, watermark, [规范禁区直译]
参数: [画幅比例] [风格化强度] [seed]
```

### 按域模板差异

| 域 | 要点 |
|---|---|
| UI 图标 | flat style、单主体居中、纯色底、no text;成组出图保批次一致;产出后人工规整进图标网格 |
| 角色原画 | 先概念 keyframe 定气质,再补三视图(AI 三视图一致性差是已知短板);筛选剪影优先 |
| 场景概念 | 注明视角类型(isometric / 横版 / 自由镜头)、时间天气、对应色彩脚本的情绪节点 |
| 特效参考 | 只产关键帧气氛与形状语言参考,不产可用序列帧 |

### 工具参数映射

出图工具未定,骨架保持通用:画幅与风格化强度写进 prompt 文字;负向以 "avoid: …" 表达;无 seed 能力时靠风格锚 + 同批同描述保持一致。首次实际使用某工具时在本节补该工具的参数对应(画幅 / 风格参考 / 负向 / seed),届时再建表——不预留空表。

## 注意事项(Pitfalls)

- **prompt 不是规范。** 好用的出图词想进规范,必须先经 art-director 定调、art-bible 落档。
- **探索图 ≠ 定稿。** 拿探索图当既成风格是走私定调。
- **负向提示不可省。** 移动端资产需要干净剪影与低噪底。
- **别把假设写成事实。** 探索模式的每张产出都带「未定调」标注。

## 验证

- 基准来源已声明(规范条款 / 探索假设)。
- 每条 prompt 含负向提示与参数层;同批参数一致。
- 变体差异说清;筛选四关结论已给。
