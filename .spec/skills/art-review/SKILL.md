# Art Review(美术资产审查)

对照美术规范审查美术资产与设计稿,产出三级裁决与可执行修改意见。规范基准在 `knowledge/standards/art-direction.md`(落点定义见 [art-bible](../art-bible/SKILL.md))——审查只对照、不立法。

## 何时使用

- 收到 UI 稿、原画、特效、场景、AI 产图等美术产出需要评审。
- 资产进版前的质检;检查产出是否偏离既定风格。

## 操作步骤

1. **定基准(含降级)。** 读规范对应域小节。**规范未建立时**:显式声明「无规范在案,按行业通用判准 + 会话内临时基准评审,结论不具规范约束力」;评审后把暴露出的规范空白路由 [art-director](../art-director/SKILL.md) 定调——**绝不静默发明规范**。
2. **四层对照,前层不过后层不看。**
   - **L1 风格一致性**:支柱逐条对照;色板合规;比例语言;**与已入库资产并排对比**——一致性是和家族比,不是和抽象理想比。
   - **L2 可读性 / 功能**:实机尺寸(25% 缩放)测试;玩法信息优先于装饰;剪影 / 层级测试。
   - **L3 技术合规(TA 视角)**:尺寸与压缩格式、图集归属、命名目录、导入设置、性能指标(面数 / 骨骼 / 粒子 / overdraw)、shader 白名单。
   - **L4 落地还原度**:引擎内截图 vs 设计稿并排;色彩偏移归因(资产问题还是场景灯光,TA 裁定)。
3. **裁决(三级)。** 通过 / 有条件通过(条件清单 + 截止时间,登记为债务、不阻塞下游)/ 退回。退回意见每条:问题定位(截图标注或坐标)+ 违反条款(降级模式注明临时基准)+ **数值化期望**(「标题字号 20→24」,不写「大一点」)+ 严重级;单次退回聚焦 ≤3 个主要问题,小毛病并入条件清单。
4. **回流。** 同类问题第二次出现 → 记 [lessons](../../knowledge/lessons.md);同类退回 3 次 → 路由 art-director 定调后由 [art-bible](../art-bible/SKILL.md) 补条款,AI 产图问题另修 [art-prompt](../art-prompt/SKILL.md) 模板。

## 快速参考(域 × 差异化检查点)

| 域 | 检查点 |
|---|---|
| 2D UI | 九宫格拉伸无畸变;最长语言文案不溢出;暗色场景弹窗仍可读;控件四态 + 空态齐全 |
| 原画 | Spine / 骨骼拆件合理;换装分件边界干净;蒙皮无穿插;剪影可识别 |
| 特效 | 低端机降级版本存在;色彩语义编码正确;不遮 UI 关键层;粒子在档位预算内 |
| 3D 场景 | LOD 切换无跳变;烘焙无漏光;texel density 达标;套件复用已登记 |

通用评判维度见 [art-director](../art-director/SKILL.md) 五域表,此处不复述。

## 注意事项(Pitfalls)

- **无规范不硬审。** 降级必须显式声明,结论不具约束力。
- **裁决要引条款。** 「感觉不对」不是审查意见。
- **审查不顺手立法。** 空白走定调流程,不在审查里现编规范。
- **性能是美术问题。** L3 技术层不过 = 整体不通过。

## 验证

- 基准来源已声明(规范条款 / 临时基准)。
- 三级裁决明确;每条意见含定位、依据、数值化期望、严重级。
- 规范空白与复发问题已回流,或声明无。
