# 0033 · 炸弹人新增中毒弹与麻痹弹两种炸弹技能,技能糖池偏向炸弹类,决赛圈宝箱保底开出炸弹糖

- 日期:2026-09-26
- 状态:生效

## 背景

用户 2026-09-26 在第 4 轮原型(ADR [0030](0030-bomber-characters-exclusive-skills-and-combos.md))进行中追加反馈:

> 「标准，爆炸类型太少了。我们只有火焰类型，按理说还有冰冻类型。或者还有类似中毒弹、麻痹弹。麻痹弹会让行速极其缓慢；中毒弹则会持续掉血。还有冰冻弹，就是直接冰住。」
>
> 「我觉得可以从宝箱掉落里边去随机的获取。」

现状:炸弹槽只有冰冻弹、穿透弹(与组合技冰川弹)三种可拿到的形态;0030 的技能糖池六种等权,炸弹类只占 1/3,木箱 50% 出技能糖、决赛圈宝箱每个多喷 1 颗、种类也从整池等权抽——一局里多数玩家打的仍是标准弹,「爆炸类型太少」的观感由此而来。`design.md` §8.4 的火焰弹 / 分裂弹暂缓,§12 的燃烧 DoT 首版非致死。

用户把全部取舍委托给主 loop 决定。

## 决策

- **炸弹槽新增两种技能,与冰冻弹、穿透弹并列:** 都是技能糖、占炸弹槽、同技能合成到 Lv3、死亡照 0030(D8)掉落;暂不新增组合(组合表即数据,后续可加)。
  - **中毒弹:** 直击照常 −1 心(同标准弹);命中且未被泡泡 / 重生保护挡下、活下来的玩家中毒,持续 L1 / L2 / L3 = 3 / 4 / 5 秒,**每秒 −0.5 心**;**可致死**,击杀者 = 投弹者,死因记新的「中毒」(与毒圈区分,死亡回顾写「被 X 毒倒了」)。重复命中刷新持续时间、不叠加速率,击杀归属改记最近一次命中的投弹者。**释放泡泡、吃血包、死亡会解毒**;泡泡期间不掉毒血。血包在中毒时满血也能吃。
  - **麻痹弹:** 直击照常 −1 心;命中且未被挡下、活下来的玩家麻痹,**移速降到 30%**,持续 2 / 2.5 / 3 秒;重复命中刷新持续时间、不叠乘。泡泡与重生保护挡;死亡清除;释放泡泡**不**解麻痹。麻痹时公开的「当前移速」同步变慢(基础移速不变),Bot 与 HUD 直接读到;水中减速与麻痹相乘。
  - **冰冻弹不变:** 直击 + 冻住 0.8 / 1.0 / 1.2 秒(0030 Q1 裁定)。
  - 与冰冻同一口径:同一颗弹的伤害先结算,只对幸存者上状态;被打死的人不会中毒 / 麻痹。
- **来源:从宝箱随机开出(修订 0030 的「池内等权」与宝箱技能糖):**
  - 技能糖池权重:炸弹类(冰冻弹 / 穿透弹 / 中毒弹 / 麻痹弹)各 **2**,泡泡 / 闪现 / 火焰光环 / 踢弹各 **1**——炸弹类约 2/3。木箱仍是 50% 出技能糖,按此权重抽。
  - 决赛圈强力宝箱喷出的那颗技能糖改为**保底炸弹类**(从四种炸弹糖按权重随机);原型保留开关可切回整池。
  - 积木与小补给箱仍不出技能糖。
- **一眼可辨:** 炸弹本体、爆炸火焰调色与中招状态各有专属表现——标准 = 橙火;冰冻 = 冰蓝 + 冰块;中毒 = 毒绿烟雾爆炸、中毒玩偶冒绿泡、本人心形变绿;麻痹 = 电黄火花爆炸、麻痹玩偶身上电弧、走路动画放慢、HUD「麻痹中」。技能糖各有造型与图标;击杀播报 / 死亡回顾写明「中毒弹」「麻痹弹」。
- **Bot:** 技能糖估值纳入两种新炸弹(炸弹槽空就要);危险判断照常(爆炸格即危险,形状与标准弹相同);自己被麻痹时按公开的当前移速规划逃生;中毒时更积极找血包、放泡泡。
- **不选的方案:**
  - 「中毒不致死(同 §12 燃烧首版)」:用户原话是「持续掉血」,不致死的毒在决赛圈里没有威胁,也无法产生击杀归属;致死并记投弹者让它成为真正的击杀手段。
  - 「麻痹 = 短冻结」:与冰冻弹重复;用户明确区分「行速极其缓慢」与「直接冰住」。
  - 「新炸弹只从宝箱出、不进木箱池」:决赛圈前一局只开 0–5 个宝箱,拿到的人太少,「类型太少」的观感改善不了。
  - 「同时加中毒 / 麻痹组合」:先验证单体手感,组合表即数据,后续按数据加。
- **锁与不锁:** 锁「中毒弹 / 麻痹弹是炸弹槽技能糖 + 中毒可致死记投弹者 + 麻痹减速公开在当前移速 + 泡泡挡两者、泡泡与血包解毒 + 宝箱技能糖保底炸弹类 + 各形态一眼可辨」;不锁中毒时长与速率、麻痹时长与减速比例、池内权重、宝箱保底开关、木箱技能糖占比,全部进 `design.md` §15(推断待验证)。

## 后果

- `design.md` 修订:上游行、§5.2(新炸弹 × 水方格)、§7.3(炸弹形态与 `BombKind` 扩值)、§8.2(来源与权重、宝箱保底)、§8.4(两行 ★ 中毒弹 / 麻痹弹)、§12(中毒 / 麻痹两行)、§15(中毒、麻痹、糖池权重三行)、§17(事件与指标)。ADR 0030 状态记「技能糖池权重与宝箱技能糖被本 ADR 修订」。
- **契约影响(本 ADR 不改契约):** 契约 v2 的 `BombKind` 只到 4、`PlayerDied.Cause` 只到 2,也没有中毒 / 麻痹状态与解毒事件。原型一律标 NON-CONTRACT:`BombKind` 扩值 5 中毒 / 6 麻痹;`PlayerDied.Cause` 扩值 4 中毒(毒圈 3 已是原型扩值);玩家的中毒 / 麻痹结束 Tick;`玩家属性.移速当前` 在麻痹时含修饰(契约只说当前账,原型首次让它与基础账分叉);中毒 / 麻痹 / 解毒三个表现事件;技能表两行、技能参数「减速千分比」;规则参数「宝箱技能糖池」「中毒间隔 / 每次点数」。是否提给契约,等原型验证后另议。
- **代价:** 中毒可致死让残血玩家在被命中后即使躲开也可能死,「死亡可解释」依赖绿色心形与死亡回顾写明中毒弹(§9.6);麻痹 30% 接近「软冻结」,与冰冻叠加时追杀是否无解由 §15 验证。糖池偏向炸弹类会让主动 / 被动技能更少见、进化更难凑,由 §15 的进化次数指标兜底。技能糖池从 6 种扩到 8 种,拾取冲突(占槽捡不起)会更常见——炸弹槽只有一个,已持冰冻 / 穿透的人捡不起中毒 / 麻痹。
