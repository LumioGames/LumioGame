# 0001 · 美术总监做成 art-* 技能族而非子 Agent

- 日期:2026-08-28
- 状态:生效

## 背景

项目需要覆盖美术全域(整体风格 / 2D UI / 原画 / 特效 / TA / 3D 场景)的「美术总监」能力,含四个功能:对话顾问、规范沉淀、AI 出图 prompt、资产评审;且美术风格尚未确立,需从零定调。`agents/` 的准入门槛是「隔离本身即是产出价值」(当前仅 `reviewer`),而美术顾问恰恰需要与用户同上下文对话,隔离有害无益。

## 决策

- 以 4 个技能承载,按功能拆分:`art-director`(hub,讨论与定调)、`art-bible`(规范沉淀与维护)、`art-prompt`(出图提示词)、`art-review`(资产审查);不新增子 Agent。
- persona 只放技能标题与开场框架,正文保持纯方法论(沿用 spec-steward 范式)。
- 单一权威分工:五大美术域分类在 `art-director` 快速参考;规范唯一落点(`knowledge/standards/art-direction.md`,膨胀才拆域文档)定义在 `art-bible`。
- 规范文档待首次定调后由 art-bible 流程建档,不预建空文档(避免白付导航税、违反「未定调不入库」)。

## 后果

- `art-review` 在主 loop 同上下文执行,无「写 ≠ 审」独立性——可接受,因其审查对象是外部美术资产而非本会话代码产出;未来若需对抗式美术评审,按准入门槛新增 agent 并以新 ADR 取代本条。
- 风格未锁定期间,art-prompt / art-review 以「显式标注假设」的降级模式工作,产出不具规范约束力。
