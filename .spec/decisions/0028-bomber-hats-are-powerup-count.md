# 0028 · 炸弹人取消独立的帽子资源,帽子只表示身上的强化数

- 日期:2026-09-25
- 状态:生效

## 背景

同日的 ADR [0027](0027-bomber-powerup-pickup-mints-hat.md) 刚把「吃强化铸帽」加进帽子经济,用户随即进一步定调:**没有帽子这个概念了,帽子只是表现,只表明这个人身上有多少个强化技能**;死亡掉落时,帽子数量跟着强化一起减少。

这推翻了自 ADR [0006](0006-bomber-hat-scoring-rolling-room.md) 起的「帽子是独立计分资源」模型:击杀铸帽、HatPile 散落 / 拾取 / 超时回收、帽子守恒账都失去对象。

## 决策

- **帽数 = 当前强化级数之和**:(火力 − 初始) + (炸弹数 − 初始) + 速度级数,纯派生、不单独存储结算;血包不计。吃强化 +1、掉强化 −1,上限由强化上限决定(首轮最多 17)。
- **胜负与帽王不变口径、换了内容**:局终帽子最多(= 强化最多)者胜;帽王 = 帽数最多且 ≥ 1(并列保留现任);光柱、箭头、Top-10 照旧按帽数。
- **死亡**:常规阶段强化每级 50% 掉落(ADR [0025](0025-bomber-final-circle-and-death-drops.md) 保留),帽塔同步变矮;**决赛圈内死亡(出局)强化全部掉落**、帽数归零——否则出局者仍可能按帽数胜出,与 0025「最后一命」矛盾(本条为设计侧补充裁决)。
- **取消**:击杀铸帽(0011 起)、吃强化铸帽(0027)、HatPile 散落 / 拾取 / 15 秒回收(0014「HatPile 表示法」)、帽子守恒账。击杀的收益 = 死者掉出的强化,谁捡归谁。
- **锁与不锁:** 锁「帽子是强化数的表现、没有独立帽子资源」;不锁 50% 掉率、强化上限、帽王光柱阈值。

## 后果

- 取代 0027 全文;取代 0011 / 0014 / 0025 中所有把帽子当独立资源的条款(铸造、散落、HatPile、帽子守恒、「死亡帽子全散」)。`design.md` §1 / §2 / §3 支柱 3 / §4 / §4.2 / §8.5 / §8.6 / §9(整节重写)/ §9.6 / §12 / §14 / §15 / §16 / §17 随之修订。
- **分数即实力**:领先者同时最强,滚雪球风险高于「帽子无数值」的旧模型;制衡靠强化上限、死亡掉一半、决赛圈与全场围攻帽王。后期多人顶到上限会并列,按 §4 平局规则(存活 / 出局先后)排序。由 §15「帽子 = 强化数」一项验证。
- **契约影响(本 ADR 不改契约)**:契约 v2 的 `BomberPlayerState.HatCount` 与 `BomberHatPile` / `HatPile*` 事件在此模型下变为派生值 / 不再使用;是否从契约删除,等原型验证后走契约修订。原型里 `HatCount` 直接填派生帽数,不再产生帽堆。
