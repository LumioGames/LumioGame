# 0042 · 炸弹人地形重做:水改为环绕核心的护城河(防火线 + 桥作卡点 + 冰冻弹结冰桥),取消溺水;新增爆炸桶,取代鞭炮;不做草丛

- 日期:2026-09-28
- 状态:生效

## 背景

用户 2026-09-28 反馈「之前设计的水很不明显……无论是表现还是功能上都感觉很弱,没有起到专业地形因素的作用」「地形之间还是比较弱,感觉地形之间的这种配合没有明确出来」。现状(读码):水每象限一个 3–4 格小水塘(全图 3–4%),规则全是负面(减速 30%、每秒 −0.5 心溺水、放弹熄灭),正面作用(火到水面停、踢弹入水拆弹)没有表现,Bot 只会绕开;水面颜色与冰冻弹撞色、进水无水花。材质表里的木头 / 鞭炮 / 冰面全排在 Stage 5 未做。

讨论中用户一度选了「河道 + 草丛 + 爆炸桶」;方向 B(ADR 0038)确立「威胁全可见」后,草丛隐身与之冲突,且正式引擎需要按连接过滤可见性,收敛为护城河 + 爆炸桶。

## 决策

- **护城河**(取代 §5.1「水方格」的池塘形态与溺水规则):
  - 布局:核心外一圈(到中心切比雪夫距离 d = 5,宽 1 格)+ 四边中点 4 座陆桥 + 4 条斜向外伸的支流,全图约 8%;四象限镜像。
  - 规则:可涉水、减速 30%、不能放弹(放下即熄灭);火焰烧到第一格水面就停——**河是防火线,桥是卡点**;**取消溺水**。踢进水里的炸弹熄灭、炸弹数返还(默认踢弹,ADR 0041)。
  - **冰冻弹炸到水面**:被火焰覆盖的水格结成冰桥 8 秒(可走、不减速、可放弹);火焰弹或任何留火碰到冰桥即融回水。
  - 表现:流动的深蓝水面、进水水花、熄灭蒸汽;冰改为白色系,与水区分;防火线处火焰撞水有「嗤」声与白汽。
- **爆炸桶**(取代 §5.1「鞭炮」):每象限 2 个(外圈、中圈各 1),占格挡火;被任何爆炸触及 → 0.1 秒后以火力 3 十字爆炸,计入同一连锁,击杀归触发者;**带上引爆它的炸弹效果**(火焰弹 → 留火,冰冻弹 → 冻人 / 结冰桥,其余 → 标准);再生时低概率长回。
- **不做**:草丛(隐身违反支柱 8「威胁全可见」,正式引擎还需按连接过滤可见性)、爆炸导电 / 毒水(每种元素一条水规则,概念超预算)、鞭炮(由爆炸桶取代,语义更直白)、木头留火(留火由火焰弹承担)。
- **不选的方案**:
  - 「河道 + 导电 + 毒水 + 冰桥」全套:三种水反应要记表,违反支柱 7。
  - 保留溺水:它让水成为纯惩罚死格,正是用户说「很弱」的原因;河改为防火线后,躲进水里本身就要付出减速与不能放弹的代价。
- **锁与不锁**:锁「护城河环绕核心、河是防火线、桥是卡点、冰冻弹结冰桥、取消溺水、爆炸桶继承引爆效果、不做草丛」;不锁宽度、支流形态、8% 占比、冰桥 8 秒、桶数与火力,全部推断待验证,进 `design.md` §15。

## 后果

- 修订 ADR 0017 的「水改为可溺死」条款(本 ADR 取消溺水;0017 其余继续有效);修订 `design.md` §5.1、§5.2、§5.3 断言 2 / 3(水 ≤ 5% 改为护城河约 8%,保留「不得封死通道、水边留陆路」)、§12(删溺水行)、§15、§17(删 `drown_death` 等事件)。
- **方块写入(约束 5 / A8)**:冰桥每次 ≤ 爆炸覆盖的水格(一颗弹最多 4 向 × 火力),两次写入(结冰 / 融化);爆炸桶等同积木破坏;均为低频、有上限,进 §15 与 A8 核数。
- **契约影响(本 ADR 不改契约)**:爆炸桶、冰桥为原型 NON-CONTRACT 材质扩展;材质行为绑定归本仓(ADR 0016)。
- **原型改动(M2)**:`sim/mapgen.ts`(护城河 + 桥 + 支流、爆炸桶,镜像与 1×1 可进入、全图连通断言)、`contract/materials.ts`、`sim/effects.ts`(删溺水)、`sim/explosion.ts`(桶连锁与效果继承、冰桥)、新建冰桥计时、`view/world/terrain.ts`(流动水、水花、冰桥、桶);Bot 把护城河当防火线、桥当卡点、桶进危险图。
