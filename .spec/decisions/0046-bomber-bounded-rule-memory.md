# 0046 · 炸弹人权威规则记忆归组件快照，按有效配表推导对象预算

- 日期:2026-09-27
- 状态:生效（规则记忆原则继续有效；19×19/8 人数字仅为旧预算包络）

## 背景

[0017](0017-bomber-explosion-and-health-model.md) 将同弹命中集合描述为不持久的服务端临时结构。当前 [v3 草案](../../docs/specs/bomber/stage0-kernel-contract.md) 的确定性哈希来自引擎快照；命中、待结果与转移所有权会影响后续规则，遗漏它们会使相同哈希对应不同后续行为。同时，炸弹库存归还早于留火结束，单用人数乘库存不能约束实体数量。

按 [四轮开工授权](../archive/plans/2026-09-27-101-bomber-engine-build-prompt.md) §5.1 的常规策划取舍权限，采用以下游戏内表示和预算。世界仍只有体素与实体，不改引擎 ABI、公共错误或 T/P/F 待裁定语义。

## 决策

### 1. 规则记忆进入现有快照

部分取代 0017「同弹命中记忆不进契约」条款：权威命中/去重记忆归游戏组件，使用 `Scope.None`、`Authority.Server` 和 `[Persist]` 的受支持字段/容器。不复制给客户端，但由声明生成器进入既有 `CaptureSnapshot()` 与 StateHash，不另造哈希输入或静态字典真值。0017 的炸弹实体、四臂、半心点与水规则保持。

规则记忆包括命中 pending/applied、炸弹接触宝箱、连锁已用/预留伤害、暴露与所选来源、非可花费转移与容量预留。每类在启用生产路径前必须有有限容量、完整身份、释放条件和真实快照证据。现阶段不因列出类别就视为字段已实现或接口已冻结。

同弹的「同一玩家」指固定对局 Participant；目标生命与 generation 另存，旧结果不得改绑 CurrentLife。来源保留完整 Participant/Life/generation/Bomb。成功的零伤害冻结接触也去重，拒绝的 pending 可释放；实际结果关联只能使用批准并发布的 GAS 接缝。

`Persist` 不授予存档重启产品功能。仅支持作者时静态底图恢复；未完整恢复耦合规则记忆的活动局必须明确拒绝，不能清空命中表后继续游玩。组件隔离恢复测试不构成活动局恢复支持。

### 2. 有效配表预算与失败边界

采用 [design §7.6](../../docs/specs/bomber/design.md#76-旧-1919-首轮对象预算与规则记忆) 的公式与来源分类。所有 overlay 应用后，使用引擎 Tick 换算和 checked 算术验证最低容量，低于要求、溢出或未知生产来源在准入前拒绝。旧 19×19/8 人独立 profile 共用供给为炸弹2784、掉落698、火墙336；旧默认最低2496/634/336。它们是推断待验证的历史包络，包含尚待生产证明的驻留余量 S=2，不是性能实测，更不能覆盖 ADR 0044 的 12/23 默认、16/27 对照及三级箱、补给、狂暴、集束、爆炸桶、冰桥等新生产者。正式准入前须重新计算所有有效档位与生产寿命。

放弹次数 Q 按 Participant/Tick 跨生命、退款和递归累计。当前业务相可见的炸弹均参与同 Tick 连锁，不加下一 Tick 资格延迟。预留/退休超过 S 时必须证明新上界并重新计算，不能隐藏无限 pending 队列。

主动放弹/火墙在库存、CD、保护与位移副作用前预留；地形产出在致因提交前预留。死亡掉落把既有财富移到 Participant 所有的不可花费 pending，直到实际地面实例接手，不能双花、重复发行、过期或丢弃。普通掉落不超时消失。容量耗尽不能裁掉旧炸弹、火墙覆盖或已接受伤害。

### 3. 宝箱与重叠火区

宝箱仅保存 RequiredHits 个不同完整 BombId；每颗炸弹另记至多本局宝箱发行数的已接触 ChestId，OpeningPending 时也记接触。失败清除 pending 后保留饱和计数，后续新炸弹接触才可发起新请求，持续同弹不自动重试。PendingTransactionId 保存 SDK 原始 string，Ordinal 比较，配合 MatchId/SubmittedTick 及 World 账本里的具体操作/格子关联；不转数字、不截短、不自定字符串长度。计数有界不等于字节上界已证。

当前光环/火墙共用目标生命的连续暴露时钟，伤害与间隔取有效表。所选来源仍有效覆盖时保持；失效才按开始 Tick、完整来源 Participant、完整来源实体、种类/技能稳定排序换源，换源不清暴露进度。脉冲下单时快照来源及目标生命，后续移动/死亡不改写已发请求。光环随施放生命死亡终止，火墙继续至到期。该规则不合并圈毒、中毒或炸弹 Danger；ADR 0042 已取消现行设计的溺水。

## 后果

- 第一轮验证声明/生成/配表算术与真实快照表示；第二轮及后续门证明 Q、同 Tick 连锁、有限驻留、守恒、失败路径和来源行为。不得互相代替。
- design 与 v3 草案同步当前规则；旧 ADR 正文保留，导航指明部分取代。违反当前规则的旧字段/表必须迁移并重新生成。
- T/P/F 与自动后继准入仍按各自接缝处理，本决策不冻结其语义，也不宣称当前发布物已支持全部规则。
