# 0034 · 炸弹人角色平衡第一轮:削棉花兔回春、加强泡泡 / 闪现 / 火焰光环,普通档 Bot 少放技能

- 日期:2026-09-27
- 状态:生效

## 背景

用户 2026-09-27:「调一下角色平衡，让 D 达标」,取舍全部委托给主 loop。

D 是第 4 轮验收(`design.md` §15「Bot 难度分档」):脚本「普通水平玩家」(`player` 档:反应 3–5 Tick、噪声 5%、不设陷阱、同时 1 颗进攻弹)对 7 个 normal Bot 打 ≥ 30 局,进前 3 ≥ 50%。ADR [0030](0030-bomber-characters-exclusive-skills-and-combos.md) 落地后实测 D = 43%(官方种子 1–30),E(唯一存活)= 100%。

实测的失衡是「角色比打法更决定名次」:

- 官方 D 批次里,脚本玩家用棉花兔 6/7 进前 3,火焰熊 3/7,泡泡鸭 2/8,闪电猫 2/8;第 1 名按角色为兔 16 / 鸭 8 / 熊 6 / 猫 2。
- 留出种子 5001–5200(200 局,D 口径)上,全 8 席第 1 名占比为兔 / 鸭 / 猫 / 熊 44.5 / 27.5 / 10.5 / 17.5%,§15「角色平衡」要求每个角色落在 25% ± 10 个百分点内。
- 光环改按暴露时长扣血之前,是火焰熊独大(约 60% 的出局者死于熊)。

调参约束(不在本 ADR 范围内改动):`player` 档本身、normal 档的 D9 定值(反应 4–7 Tick、噪声 15%、不设陷阱)、胜负规则、安全圈段表与毒速、D / E 的阈值与种子都不动。调参只在留出种子上做(D 5001–5200、筛选 7001–7200,E 6001–6040),官方种子只在最后跑一次。

## 决策

- **四个专属技能改数值,结构不变**(`src/contract/skills.ts`,`design.md` §8.0 / §8.4):

  | 技能 | 调整前 L1 / L2 / L3 | 调整后 L1 / L2 / L3 |
  |---|---|---|
  | 回春(棉花兔) | 每 10 / 8 / 6 秒回 1 心 | 每 **20 / 16 / 12 秒回半心** |
  | 泡泡(泡泡鸭) | 持续 3 / 3.5 / 4 秒,CD 18 / 15 / 12 秒 | 持续 **3.5 / 4 / 4.5 秒**,CD **14 / 12 / 10 秒** |
  | 闪现(闪电猫) | 3 / 3 / 4 格,CD 12 / 10 / 8 秒 | 3 / 3 / 4 格,CD **10 / 8 / 6 秒** |
  | 火焰光环(火焰熊) | 持续 4 / 4.5 / 5 秒,CD 20 / 17 / 14 秒 | 持续 **5.5 / 6 / 6.5 秒**,CD **16 / 14 / 12 秒** |

  回春、泡泡、光环的 L1 与闪现 CD 原是用户第 4 轮口述,本 ADR 按用户这次的委托改掉,口述值留作 §15 的 A/B 对照。烧伤速率(每秒 −1 心,按暴露时长)不变。
- **Bot 调整(原型工具,`src/contract/ai.ts`):**
  - normal 档满足条件时真正施放技能的概率 700‰ → **200‰**。D9 定值不动。
  - easy 档 400‰ → **100‰**,保持 easy < normal < hard(1000‰)。
  - 光环施放距离(切比雪夫)1 → **2**:光环更长,熊隔一格就开。
- **不选的方案:**
  - 「只改角色数值」:在 D 的轮换口径下近乎零和。兔的第 1 名占比从 44.5% 降到 23%,但 D 只多 3 个点(200 局 45%,配对比较不显著)。
  - 「闪现 4–5 格 / CD 5–7 秒」「更强的泡泡」「normal 思考间隔 3 Tick、爆炸 / 交战缩放 750‰、放弃进攻 300‰」「更激进的 normal」:筛选批次(各 200 局)都是持平或更差(40–47%)。
  - 「normal 施放概率 100‰」:留出种子 52%,与 200‰ 的 51% 持平;但猫 / 兔在 E 的占比跑出 15–35% 之外,Bot 也几乎不再用技能(鸭 Bot 场均约 1.9 次)。
  - 「加强 `player` 档或改 D 的定义」:都在这次授权之外,留给策划评审(见后果)。
- **锁与不锁:** 结构不变:四个专属技能、三槽、组合表、烧伤按暴露时长扣血都不改。所有数值(上表、两档施放概率、光环施放距离)都是推断待验证,登记在 `design.md` §15。

## 后果

- `design.md` 修订了这几处:§8.0 选角一句话(回春、泡泡、光环);§8.4 四个专属技能的 L1 / L2 / L3;§15 的泡泡、回春、闪现、火焰光环四行(新值,原值作 A/B)、「角色平衡」行(实测占比)、「Bot 难度分档」行(三档施放概率与官方 D 结果)。
- **实测:** Wilson 95% 区间。
  - **留出种子 D**(5001–5200,200 局):进前 3 从 42%(84/200,[35%, 49%])升到 **51%(102/200,[44%, 58%])**。同种子配对比较是 59 升 / 41 降(z = 1.80),连同筛选批次合计 51.5%(206/400,[46.6%, 56.4%])。
  - **全 8 席第 1 名占比**(兔 / 鸭 / 猫 / 熊):从 44.5 / 27.5 / 10.5 / 17.5% 变为 22.9 / 30.3 / 14.9 / 31.8%。
  - **脚本玩家按角色进前 3**(兔 / 鸭 / 猫 / 熊):从 58 / 34 / 28 / 48% 变为 46 / 52 / 54 / 52%。名次不再由脚本玩家拿到的角色决定。
  - **E 留出种子**(6001–6040,40 局):唯一存活保持 100%。第 1 名占比从 47.5 / 25 / 10 / 17.5% 变为 20 / 25 / 25 / 30%。
  - **easy / hard 旁证**(5001–5060,60 局,脚本玩家进前 3):hard 从 47% 升到 55%;easy 在只改 normal 时为 37%,easy 施放概率降到 100‰ 后为 55%。normal 在同一批种子上是 58%。
  - **官方种子(一次):**
    - **E** 20/20 唯一存活(**100%**,通过)。
    - **D 37%**(11/30,[22%, 55%]),**未达标**。调整前为 43%(13/30,[27%, 61%])。第 1 名按角色是鸭 10 / 熊 9 / 兔 7 / 猫 4。脚本玩家用猫 0/8 进前 3,用鸭 5/8、兔 3/7、熊 3/7。
  - 30 局的区间宽达 ±16 个百分点,官方 D 这次比调整前低,落在种子噪声之内,与 200 局留出种子的提升并不矛盾。但官方口径下 D 仍未通过,`pnpm stats` 照旧以 D 断言失败退出。本 ADR 不改断言、不换种子。
- **没解决的:**
  - **D 的上限在 `player` 档本身。** 它只比 normal 略强(反应快 1–2 Tick、噪声 5% 对 15%)。约 43% 的出局是决赛圈里的自毒,这点优势几乎影响不到。能动的杠杆中,只有「normal 少放技能」(即扩大脚本玩家的技能优势)一项动过 D,而且越往下收益越小。要稳过 55%(真实值 ≥ 50% 的把握),需要加强 `player` 档或改 D 的定义,这交给策划评审(`design-review`)另议。
  - **闪电猫的第 1 名占比**在所有候选里都停在 10–15%,是唯一没稳进 15–35% 带的角色,官方 D 中脚本玩家用猫 0/8 进前 3。下一轮平衡先看猫(闪现的 Bot 用法与逃生落点)。
  - **跨档旁证有倒挂。** 调整前,脚本玩家对 easy 反而比对 normal、hard 差:hard Bot 多互相毒死,对 hard 的出局 67% 是自毒。调整后 easy 55% ≈ hard 55% < normal 58%,仍未体现「easy 最容易」。这是 Bot 档位设计问题,不是角色平衡问题。
