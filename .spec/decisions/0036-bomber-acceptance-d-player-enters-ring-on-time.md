# 0036 · 炸弹人验收 D:脚本玩家按时进圈、不学 Bot 晚进圈,官方 D 由 30 局扩到 100 局

- 日期:2026-09-27
- 状态:生效

## 背景

验收 D(`design.md` §15「Bot 难度分档(原型工具)」)的内容是:脚本「普通水平玩家」(`player` 档)对 7 个 normal Bot,进前 3 的比例 ≥ 50%。ADR [0034](0034-bomber-character-balance-round-1.md) 做完角色平衡后,留出种子上是 51%,官方种子 30 局是 37%,未达标。0034 的结论是:上限在 `player` 档本身;要稳过,需要加强 `player` 档或改 D 的定义,交策划评审。

复盘发现,`player` 档和三档 Bot 共用同一套决赛圈打法,包括 Bot 的「晚进圈」战术:圈外格子待到下一次收缩前 `BOT_TACTICS.lateEntryTicks` 才进圈(`showdown.ts` `lateEntryHorizon`)。这是为 Bot 调出来的「在毒边上卡位」打法,不是普通人的行为。实测脚本玩家约 43% 的出局死于决赛圈自毒。

用户 2026-09-27 定调:D 的含义是「让脚本玩家更像普通人」。
- `player` 档保留反应 3–5 Tick、噪声 5%,不加强反应与噪声。
- 改成像普通人一样:下一圈一预告就按时走进去,不做 Bot 专有的在毒里逗留。
- 官方 D 从 30 局扩到 100 局(种子 1–100),阈值 ≥ 50% 不变。
- 上线前先在留出种子上验证,≥ 200 局的点估计要 ≥ 55%。

## 决策

- **`BotProfile` 新增进圈纪律 `ringEntry: 'late' | 'onTime'`**(原型扩展 NON-CONTRACT,`src/contract/ai.ts`):
  - easy / normal / hard 三档 Bot 仍是 `'late'`,行为不变。验收 E 依赖这三档,`BOT_TACTICS` 不动。
  - `player` 档改为 `'onTime'`:
    - 摊牌期不用晚进圈的落脚时限,落脚点按「永不进毒圈」挑选(`bot-brain.ts`)。
    - 找不到普通目标时,先守在最近的圈内落脚格;被挤出圈就沿 `pickInward` 走回圈内。这两步都不行,才退回放宽毒圈的几档。
    - 躲弹时先找最近的圈内陆地格,要求永不进毒、路线也不穿毒,找不到才退回常规逃生口径(`behaviors.ts` `pickEscape`)。
    - 决赛圈之前棋盘上没有毒,这一步挑出的格子与原逃生口径相同,所以常规阶段行为不变。
- **`player` 档其余字段不变:** 反应 3–5 Tick、噪声 5%、不设陷阱、同时 1 颗进攻弹、施放概率 800‰。normal 档的 D9 定值不动。
- **官方 D 改为 100 局(种子 1–100)**,阈值 ≥ 50% 不变(`tests/stats-normal.test.ts`,断言 ≥ 100 局)。取代 §15 与 0034 口径里的「≥ 30 局」。30 局的 95% 区间宽约 ±16 个百分点,单次官方结论几乎由种子噪声决定;100 局约 ±10 个百分点。
- **不选的方案(都在留出 / 开发种子上试过,见后果):**
  - 「更严的 onTime」:回圈路线选穿毒最少的一条;再不行就选既不站在毒里也不穿毒的动作;都没有就原地不动。自毒减半,但进前 3 反而下降:玩家更多死在拥挤的中心。
  - 「血量够才穿毒逃生」:与现行版本持平,在噪声之内。
  - 「加强 `player` 档的反应 / 噪声」:用户明确不要,D 的含义是「更像普通人」,不是「更强」。
- **锁与不锁:** 锁「D 的脚本玩家按时进圈、不学 Bot 晚进圈」「官方 D = 种子 1–100 共 100 局」「阈值 ≥ 50%」。`onTime` 的具体选格顺序是原型实现,不锁。

## 后果

- `design.md` §15「Bot 难度分档(原型工具)」一行修订:D 的定义加「按时进圈」,局数改为 100(种子 1–100),附实测。原型 README 同步。
- 新增 6 个单测(`src/bots/showdown.test.ts`):
  - 三档 Bot 仍在臂上晚进圈。
  - 每个 `onTime` 性格都直奔已预告的圈。
  - normal 档只切这个开关也会直奔圈内。
  - 躲弹时 `late` 落到将变毒的格子,`onTime` 落到下一圈内。
  - 被挤出圈时 `onTime` 直接走回圈内。
- **留出种子实测**(新节奏 ADR [0035](0035-bomber-pacing-final-circle-at-two-minutes.md) 下,D 口径,种子 8001–8200,200 局,Wilson 95% 区间):
  - `onTime` 进前 3 **49.5%(99/200,[42.6%, 56.4%])**,唯一存活 98%,平均局长 192 秒。
  - 同种子把 `player` 切回 `late` 作配对基线:43.5%(87/200,[36.8%, 50.4%])。
  - 配对比较:只有 `onTime` 进前 3 的 47 局,只有 `late` 进前 3 的 35 局,净 +12,z = 1.33,方向一致但不显著。
  - **未达到上线前的 ≥ 55% 预验证线。** 用户定的是 D 的含义,不是某个数字,所以照样落地,并如实记录。
  - 自毒仍是主要损失:`onTime` 的 148 次出局里 64 次是毒圈(`late` 为 169 次里 74 次)。轨迹显示,玩家剩 1 心左右、圈内被砖 / 火 / 人堵住时,会绕道穿过毒带。
  - 开发种子 7001–7100(每组 100 局)的否决对照:「更严的 onTime」自毒 24 → 13 次,但进前 3 50% → 40%(z = −1.54);「血量够才穿毒」53% 对 50%(z = +0.63)。
  - 跨档旁证(D 口径,脚本玩家为 `onTime`,种子 8001–8060,60 局):对 easy 50%、对 normal 45%、对 hard 41.7%,符合 easy ≥ normal ≥ hard 的预期顺序。0034 记录的跨档倒挂在这一批里没有出现(60 局样本小,只作旁证)。
- **官方种子(2026-09-27,只跑一次,种子 1–100):**
  - **D = 42%(42/100,Wilson 95% 区间 [32.8%, 51.8%]),未达标。** `pnpm stats` 照旧以 D 断言失败退出(exit 1);本 ADR 不改断言、不换种子。
  - 脚本玩家第 1 名 19%,平均名次 4.2。
  - 100 局全部以唯一存活者结束,平均局长 3.2 分钟,场均帽王更替 7.1、进化 1.1。
  - 全 8 席第 1 名按角色为兔 33 / 鸭 29 / 熊 23 / 猫 15。
  - 场均毒死 2.85 次,占「击杀 + 自爆 + 毒圈」约 27%。
  - 同批 E(种子 1–20)唯一存活 100%,见 0035。
  - 官方 42% 落在留出种子 49.5%([42.6%, 56.4%])的区间下沿之外一点点。两组种子的差异仍在 100 局对 200 局的抽样噪声范围内(差 7.5 个百分点,合并标准误约 6 个百分点)。结合两组看,在这次定义的口径下,D 的真实值约在 42–50%,**低于 50% 的阈值**。
- **没解决的:** 在用户这次定义的口径下,D 仍未达标(官方 42%,留出 49.5%)。可用的杠杆(都需要另行决策):
  - 脚本玩家的决赛圈残血穿毒逻辑:剩 1 心时,穿毒的代价要按毒速和路长来算,而不是只挑最近的路线。
  - normal Bot 的决赛圈强度(`BOT_TACTICS` 摊牌参数)。它们同时影响 E,须连同 E 一起重验。
  - 重新定义 D 的阈值或指标,例如「进前 3 ≥ 45%」或「平均名次 ≤ 4」,交策划评审(`design-review`)。
