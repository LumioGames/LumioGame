# 0012 · 炸弹人由一击即死改为三颗心血量,单发削血、连锁秒杀

- 日期:2026-09-04
- 状态:被 0014 取代

## 背景

用户在 [0011](0011-bomber-100-player-io-gear-slots.md) 定调后追加:希望有血量机制让玩家有紧张感,火焰弹带掉血 debuff,有血包回血,玩家不要一次性死。「一击即死」是 0006 定下、0011 重申的炸弹人底盘条款,属核心手感的方向变更,须新 ADR 取代。

100 人 .io 混战下一击即死的隐患:大量死亡来自屏幕外的连锁与人堆,「死得明白」(设计稿平衡原则 4)难以成立;血量给「被炸一下」留出反应余地,并新增「残血逃生 / 追杀残血」的张力与血包这第二类争夺目标。代价是稀释炸弹人「每颗炸弹都致命」的品类身份,以及击杀用时上升带来的击杀与铸帽速率下降。GAS Attribute 已因据点宝箱 HP 引入,玩家血量零框架成本。

## 决策

- **每人 3 颗心**(整数),重生满心;每颗炸弹的爆炸触及 −1 心,与火力无关;同一爆炸链每颗炸弹各算一次、同一颗炸弹对同一人只算一次——**单发削血、连锁秒杀**,连锁仍是致命技术。
- **火焰弹**改为直击 −1 心并附加燃烧(每秒 −1 心,时长随等级);冰冻弹维持不扣心。
- **血包**进糖果池与据点战利品,回 1 心,满心不拾取;不做自然回血。泡泡解除燃烧并免伤;狂暴糖拾取回满;厚棉花改为心上限提高 + 高等级脱战回血。
- **击杀归属** = 打掉最后一颗心的炸弹主人(燃烧致死归火焰弹主人);帽子、装备掉落与死亡代价(0011)不变。
- **他人血量**以玩偶破损三档(完好 / 露线 / 露棉花)诊断式表达,本人的心在 HUD;首版允许用受击后短暂显示的小血条代替,进 B1 画面验证。
- **重申 0011 其余全部条款**:100 人 .io 结构、8–100 人弹性、击杀铸帽、3 槽装备与拾取规则、死亡代价构成、支柱 1/3/6、首发不做角色、三阶段切片、锁与不锁。
- **锁与不锁**:锁「血量取代即死」「单发削血、连锁秒杀」「燃烧与血包存在」;不锁心数、燃烧数值、血包掉率、显示方式(全部进设计稿待验证表)。

## 后果

- 取代 0011 的「炸弹人底盘(即死)」条款,其余由本 ADR 重申;`docs/specs/bomber/design.md` §1/§3.1/§7/§8/§9/§12/§14/§15/§16 修订,`risks-and-engine-asks.md` B6、`ugc-ladder.md` L0、`worldview.md` ① 同步。
- 品类身份让渡:「炸一下就死」的绝对紧张换成「残血」的持续紧张;若原型显示单发削血让炸弹失去威慑,回退路径是心数降为 2 或连锁伤害加倍,不回到即死。
- 击杀用时上升 → 每局击杀数与铸帽速率下降,散落超时与局时取值需随之重测。
- 美术新增:玩偶破损三档(8 向 × 3 态)与燃烧、残血表现,进 B1 清单;100 人下他人血量的读数是新的可读性风险(B6)。
- 数据纪律:心数与伤害均为整数,遵守 config IntegerOnly。
