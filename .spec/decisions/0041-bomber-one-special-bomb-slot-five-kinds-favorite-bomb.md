# 0041 · 炸弹人特殊炸弹一个槽、踩到就换、五种各有形状;每个角色一个最爱炸弹;人人默认会踢弹

- 日期:2026-09-28
- 状态:生效

## 背景

ADR 0038 的评审结论:现行三槽技能体系(ADR 0030 / 0033)「技能分不清、有点乱」——炸弹类技能全是十字、只差颜色与后续状态,专属技能也在糖池,槽满捡不起,等级是看不见的小数值,组合无提示。用户要求「角色内有组合的感觉……盲目捡不弱,但组合会更强,有一定策略性」,同时要求简单、不加按键(「我们还有移动玩法」)。讨论中用户否掉了多槽 + 丢弃的交互(「换了 A 之后扔出一个……交互上边就会很烦」),在方向 B 下选定:特殊炸弹 5 种、最爱炸弹按推荐配对、踢弹人人默认会。

## 决策

- **特殊炸弹一个槽**:身上最多 1 种;没有时放标准弹。**走过另一种特殊炸弹就换上**,旧的按原样掉在脚下(离开该格前不会捡回);不分等级;死亡 50% 掉落(决赛圈出局全掉)。捡到时屏幕显示名字 + 一句话 2 秒。
- **五种特殊炸弹,每种剪影与爆炸形状都不同**(不靠颜色区分;直击照常 −1 心):

  | 炸弹 | 一句话 | 看起来 |
  |---|---|---|
  | 火焰弹 | 爆完十字留火 1.5 秒(站满 1 秒 −1 心) | 火线停留 |
  | 冰冻弹 | 冻住被炸到的人 1 秒;炸到水面结冰桥 8 秒 | 白色冰晶 |
  | 遥控弹 | 你的炸弹不自爆,长按空格(触屏长按放弹键)≥ 300 ms 一起引爆;8 秒兜底自爆 | 天线 + 指示灯 |
  | 集束弹 | 爆完四个端点各再炸一次(火力 1,0.5 秒后) | 四朵小爆炸 |
  | 穿透弹 | 火焰穿过积木一路烧到铁皮 | 长箭头火焰 |

  集束子弹与母弹共用「同弹同人一次」、合计算宝箱 1 次命中;子弹不计炸弹数、不计帽数、不可踢。遥控的点按仍是放弹,不新增按键。
- **角色技(Shift)**:四角色专属技能不变(数值沿用 ADR 0034),**移出糖池**、永不掉落。
- **最爱炸弹**(每角色一个,写在选角卡上):捡别的不亏,捡到最爱时角色技升级——

  | 角色 | 最爱 | 效果 |
  |---|---|---|
  | 火焰熊 | 火焰弹 | 光环经过的格子留火 1 秒 |
  | 泡泡鸭 | 冰冻弹 | 泡泡破裂时冻住身边 8 格的敌人 1 秒 |
  | 闪电猫 | 遥控弹 | 闪现的瞬间引爆自己所有遥控弹 |
  | 棉花兔 | 集束弹 | 每次回春回血,脚下炸开一朵小集束花(不伤自己) |

- **人人默认会踢弹**:走进静止的炸弹就踢出去,8 格/秒滑到障碍前停下,入水熄灭、炸弹数返还;踢弹不再是技能糖。
- **来源**:中圈铁箱(50%)、核心金箱(必出)、中央大补给(2 个)、决赛圈强力宝箱(1 个)、死亡掉落;积木与外圈木箱不出。糖池五种等权(推断待验证)。
- **删除**:中毒弹、麻痹弹(`BombKind` 5 / 6 原型扩值作废);冰川弹、弹射泡泡、火焰冲刺三条组合(「火焰冲刺」的体验并入「熊 × 火焰弹」不做,猫的最爱改为遥控);三槽模型、被动 / 主动拾取技能、占槽不拾取、技能 1–3 级与合成升级;黑洞弹、快爆弹(快引信只保留在狂暴糖里);分裂 / 火焰弹旧规格以本表为准。
- **不选的方案**:
  - 「元素 × 功能 × 角色」三层组合(v2):概念超过 10 个,违反支柱 7。
  - 「多槽 + 站 0.4 秒替换」「多槽 + 自动顶掉最早的」「多槽 + 按键丢弃」:用户认为换槽交互烦、不要加键;一个槽时「换掉哪个」永远明确。
  - 「6 种(加快爆弹)」「4 种(去掉穿透)」:用户选 5 种。
  - 「最爱只给炸弹加火力」:用户选改角色技,组合感更强。
  - 「踢弹鞋作为经典糖」「去掉踢弹」:默认会踢不加概念、竞技上限更高;代价是炸弹更难困死人。
- **锁与不锁**:锁「一个槽踩到就换、五种各有形状、专属移出糖池、最爱炸弹改角色技、人人会踢」;不锁 1.5 s / 1 s / 8 s / 300 ms / 集束火力与延时 / 最爱效果数值 / 糖池权重,全部推断待验证,进 `design.md` §15。

## 后果

- **取代** ADR 0030 的三槽模型、技能糖池(含专属)、拾取判定表(§8.3)、技能等级与合成、组合表;0030 的「开局选角、专属技能绑定、基础属性相同」继续有效。**取代** ADR 0033 全文。ADR 0014「装备替换需确认」早已被 0030 取代,本 ADR 维持「不做确认」。
- `design.md` §5.2、§6(长按引爆、默认踢弹)、§7.3、§8(重写)、§9.5、§12(删中毒 / 麻痹 / 燃烧 DoT)、§14 原则 5、§15、§16 Stage 5、§17 修订。
- **契约影响(本 ADR 不改契约)**:契约 `BombKind` 标准 0 / 冰冻 1 / 火焰 2 / 穿透 3 / 分裂 4 正好覆盖五种中的四种;遥控为原型 NON-CONTRACT 扩值;遥控引爆输入(`AbilityActivation { ability: '引爆' }` 或放弹长按)为原型扩展,契约修订后置。
- **原型改动(M2)**:`contract/skills.ts`、`shared/skill-rules.ts`、`sim/skill-candy.ts`、`sim/skills.ts`、`sim/pickup.ts`、`sim/explosion.ts`(留火、冻结、集束子弹)、`sim/step.ts`(遥控)、`sim/place-bomb.ts`(每颗弹自带引信)、`sim/kick.ts`(默认踢)、Bot 危险图与用法、HUD 两格技能栏(角色技 + 特殊炸弹)、选角卡最爱、独有剪影与爆炸表现;删除中毒 / 麻痹 / 旧组合代码与测试。
- 代价:技能种类从 10 个降到 5 种特殊炸弹 + 4 个角色技;已实现的中毒 / 麻痹 / 组合代码作废。
