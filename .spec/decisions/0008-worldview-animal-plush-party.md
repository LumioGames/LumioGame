# 0008 · 世界观定调「动物玩偶派对」

- 日期:2026-08-28
- 状态:生效

## 背景

`product-direction.md` 差异化第 3 条要求统一视觉语言「玩家换游戏不换世界」,但那个「世界」完全空白——三款产品各有品类调性,没有共同的题材、世界观与角色设定;首发产品 ① 的全部使命是画面验证,「角色是什么、在哪儿对战」不能再悬置。定调探索摆出四个候选:W1 拟人动物小镇、W2 玩具盒·桌面世界、W3 体素原生方块生物、W4 动物玩偶派对(W1 × W2 混合)。用户拍板 W4。

## 决策

- **世界观 = 动物玩偶派对**:一盒被赋予生命的动物玩偶,在积木搭成的桌面世界里开派对——动物回答「谁」(识别度 / 表情 / 皮肤空间),玩具回答「在哪、为什么」(体素 = 积木、俯视 = 俯瞰桌面、多款小游戏 = 一盒桌游,与开源平台定位语义同构)。
- **三款产品落地**:① 炸弹人 = 玩偶们的积木棋盘炸弹赛,帽子计分([0006](0006-bomber-hat-scoring-rolling-room.md))与「玩偶戴帽 / 摘帽」天然贴合;② 起床战争 = 两队玩偶保卫「床头堡」;③ 鸭科夫 = 橡皮鸭潜入玩具仓库,「看着人畜无害、玩着心跳加速」的反差由玩具属性天然承接。
- **表现基线**:死亡 / 损失表现为玩偶散架、棉花飞出、零件弹开——夸张不血腥;重生语义 = 重新摆上桌。该基线是内容评审的否决依据。
- **为什么不选另外三个**:W1 纯动物需另找体素与俯视的题材解释,且「可爱动物派对」赛道拥挤;W2 纯玩具是「框」不是「角色」,角色魅力还要再答一层;W3 与「2D 手绘角色」产线直接冲突、方块脸表情弱、Minecraft 联想过强。
- **锁与不锁**:锁世界观框架与表现基线;不锁角色阵容、命名、主视觉 IP、皮肤体系(「材质换皮」仅为候选想象)。设定稿落 `docs/specs/worldview.md`。

## 后果

- 与 Party Animals(动物玩偶物理乱斗)设定相近,差异化押注在画面形态(俯视体素棋盘 + 2D 手绘角色)上;若比稿产出趋近其观感,须回到本条重新评估。
- 「玩偶感」依赖缝线、材质等贴图细节质量,对 AI 出图与贴图产线提出可验证的质量要求。
- 玩偶设定隐含「非生命体」的轻叙事调性,接受叙事纵深上限受限。
- 帽子等外观向商业化想象继续被账号级持久化(risks A5)阻塞,不因世界观定调而提前。
