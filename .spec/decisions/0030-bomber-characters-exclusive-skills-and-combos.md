# 0030 · 炸弹人开局选角色:四个角色各带一个专属技能,局内开出技能糖,两个技能凑齐自动进化

- 日期:2026-09-26
- 状态:生效（技能糖池权重与宝箱技能糖被 0033 修订）

## 背景

用户 2026-09-25 第 4 轮试玩 101 网页原型(ADR [0024](0024-per-game-directories-and-101-web-prototype.md))后反馈:玩法和技能太少、不够有趣、没有挑战。原型只有三种强化糖 + 血包,`design.md` §8 的三槽技能整体在 Stage 5 可选切片里,原型一个技能都没有;八只玩偶外观不同、打法完全相同。

用户定调:开局选角色,4 个角色每人 1 个专属技能、基础属性相同;局内还能开出技能,两个不同技能同时在身上自动进化成更强的组合技(肉鸽组合,组合表即数据);技能不计入帽塔。

与现行定调的冲突:
- ADR [0014](0014-bomber-v04-stage0-convergence.md) 重申 0011 的「首发不做角色」(0011 登记的候选形态是「起手装备包 + 外观,技能全来自公共池」);
- `design.md` 支柱 5 与 §14 原则 5 否掉「绑定 / 不可掉落装备」,专属技能天然绑定;支柱 4 否掉「开局仪式流程」,选角是一步开局流程;
- §12「不做自然回血」,棉花兔的专属技能就是回血;
- §8.1「每槽最多 1 个技能」下,首批 3 条组合有 2 条是同槽组合(闪现 + 火焰光环同在主动槽、冰冻弹 + 穿透弹同在炸弹槽),无法同时持有;
- §6 / §8.3 让 Shift 同时承担「主动技能」与「替换确认」,角色开局就带主动技能后,站在技能糖上按 Shift 必然撞键;
- §8.4 冰冻弹「不扣心」:拾取改为「空槽即装上、不能替换」之后,捡到冰冻糖的人在掉落之前再也炸不死人,决赛圈里无法换血,与 ADR [0031](0031-bomber-final-circle-to-one-cell-last-survivor-wins.md)「活到最后者胜」直接冲突。

## 决策

- **开局选角色,取代 0014 重申的「首发不做角色」。** 首批 4 个:棉花兔(被动·回春)、泡泡鸭(主动·泡泡)、闪电猫(主动·闪现)、火焰熊(主动·火焰光环)。**基础属性完全相同**(火力 / 炸弹数 / 移速 / 血量),只差一个专属技能。单屏四选一,默认预选上次角色(客户端本地记住,不是账号数据),之后每局沿用、结算页可换(下一局生效);中途加入同样先选再进。全部角色免费、无解锁(架构约束 7)。
- **支柱 4 收窄:** 「否掉开局仪式流程」改为「否掉多步开局仪式」,单屏选角是唯一允许的一步。
- **三槽保留,专属技能占自己的槽并绑定。** 兔的回春占被动槽,鸭 / 猫 / 熊占主动槽;专属技能永不掉落、永不被替换,只会被同技能糖升级(上限 Lv3),或进化成包含它的组合技。**支柱 5 与原则 5 加唯一例外:** 专属技能是身份不是财富(不计帽数);拾取的技能照常流动。
- **技能糖取代旧稿「装备箱」:** 地上可拾取的技能,带等级。池 = 闪现、火焰光环、泡泡、踢弹、冰冻弹、穿透弹,池内等权(回春只属于棉花兔、不进池)。木箱必掉 1 个,其中一半是 Lv1 技能糖;决赛圈强力宝箱每个多喷 1 个 Lv1 技能糖;积木与小补给箱不出。
- **拾取规则取代 §8.3 与 0014「装备替换需确认」,按顺序判定:** ① 与身上某个技能在组合表里成对 → 立即进化;② 同技能 → 等级 +1,已 Lv3 不拾取;③ 对应槽空 → 以糖的等级装上;④ 其余 → 不拾取、物品留地。**取消替换确认,Shift 只管主动技能。** 回退路径:若「占槽捡不起」的挫败显著(`design.md` §15),另立 ADR 引入替换手势。
- **组合进化:** 组合表是数据,首批 3 条——闪现 + 火焰光环 → 火焰冲刺(主动槽);泡泡 + 踢弹 → 弹射泡泡(主动槽,踢弹原在被动槽则腾空);冰冻弹 + 穿透弹 → 冰川弹(炸弹槽,用契约现有 `BombKind = 1` + `PierceLayers = 1` 表达,不加枚举)。**同槽组合合法**:两半合成一个技能,占组合表规定的槽。组合技单一形态、无等级、不再吸收技能糖;进化时全场可见玩偶形态变化 + 本人横幅「进化:<组合技>!」。
- **技能死亡掉落:** 拾取的技能每个 50% 掉落、保留等级(与 §8.2 装备原口径一致);决赛圈出局全部掉落;专属技能永不掉。含专属的组合:专属那一半留下(拆回进化前等级的专属技能),拾取那一半按上条掉成技能糖;两半都是拾取的:作为一个组合技糖按上条掉落。死者掉出的技能糖同享 ADR [0029](0029-bomber-death-drops-blast-protection.md) 的 3 秒防爆。
- **技能不计帽数:** 专属技能、技能糖、技能等级、组合技都不是强化;ADR [0028](0028-bomber-hats-are-powerup-count.md) 与 §9.5 不变,只补这一句。
- **回春是 §12「不做自然回血」的角色专属例外:** 距上次掉血满 10 秒回 1 心,之后每 10 秒再回 1 心直到满血(上限 = 满血 3 心,不提高血量上限);任何掉血(含溺水、毒圈)重新计时。其他角色照旧只靠血包。
- **技能首轮数值(推断待验证):**
  - 泡泡 3 秒完整无敌,挡炸弹 / 火 / 冰冻 / 溺水、不挡毒圈(与重生保护同口径),期间不能放弹、按放弹不解除,CD 18 秒(取代 §8.4「首版一次伤害护盾」)。
  - 闪现沿面朝方向(最后一次移动方向,开局朝下)最远 3 格,铁皮之后不可达,可越过积木 / 木箱 / 炸弹 / 宝箱,落在最远的空地,无落点则失败不进 CD,CD 12 秒(取代 §8.4 冲刺;瞬移不是穿墙,§5.2「穿墙首发不做」不变)。
  - 火焰光环 4 秒,以熊为中心的 3×3(含脚下)着火随人移动,敌人每秒 −1 心、可致死、死因燃烧、击杀者 = 熊,零方块写入,CD 20 秒;火焰冲刺在起点与途经格(不含落点)留 2 秒火墙,同速率。
  - 施放火焰光环或火焰冲刺立即结束自己的重生保护(与「放弹即解除」同口径,§12)。
  - 踢弹(§8.4 原有被动)按原型口径:8 格/秒滑行,玩家不挡(与移动无玩家碰撞一致),滑进水即熄灭、炸弹数返还(§5.2「踢进水 = 拆弹」原口径)。
  - L1–L3 表见 `design.md` §8.4。
- **冰冻弹照常扣心,偏离 §8.4「不扣心」:** 冰冻弹与冰川弹先按标准弹 −1 心,再冻结火焰覆盖格内存活的玩家;同一颗炸弹的伤害不解除这次冻结,之后的伤害照常立即解除并给 1 秒控制免疫;冻结不叠加、不刷新。理由见背景最后一条。原型保留开关,可切回「不扣心」对照。
- **原型边界(修订 0024):** 原型内容范围扩到 Stage 5 的角色、技能与组合进化(仅限原型;生产仍是 `design.md` §16 Stage 5 可选切片,Feature Flag 关闭时技能关闭、角色只剩外观)。0024「表现层不得依赖 NON-CONTRACT 字段才能工作」改为:表现层可以依赖 NON-CONTRACT 字段呈现原型扩展玩法(角色、技能、决赛圈、排名),但字段缺席时必须退化而不崩溃;契约内核玩法(移动、放弹、爆炸、血量、帽数)不得依赖它们。
- **不选的方案:**
  - 「取消槽类型(技能任放三格)」:丢掉炸弹 / Shift / 被动三类输入的可读性,且撞已锁的 3 槽模型;同槽组合用进化解决即可。
  - 「只做跨槽组合」:首批 3 条里 2 条是同槽,等于砍掉主要内容。
  - 「技能计入帽塔」:用户已否;会把帽子从「强化数」改回混合资源(推翻 0028 的定义),专属技能开局即计帽会让帽王失真。
  - 「技能全不掉」:拾取技能不流动,违背支柱 5,击杀收益变小。
  - 「保留 Shift 替换确认」:与主动技能撞键。
  - 「冰冻弹保持不扣心、调低冰冻糖权重」:只降低撞上的概率,捡到的人照样失去击杀能力。
- **锁与不锁:** 锁「开局选角 + 基础属性相同 + 每角色 1 个绑定专属技能 + 三槽 + 技能糖 + 组合进化即数据 + 技能不计帽 + 拾取无确认 + 专属不掉、拾取半掉」;不锁首批 4 角色名单与技能配对、组合表条目、全部数值(回春间隔、各技能时长 / CD / 距离 / 等级表、木箱技能糖占比、池内权重、冰冻弹是否扣心),全部进 `design.md` §15。

- **契约影响(本 ADR 不改契约):** 契约 v2 没有角色、技能槽与等级、冷却、无敌、冻结、朝向、回血计时、技能输入与技能事件;`AbilityActivation` 只有「移动 / 放弹」。原型一律标 NON-CONTRACT:玩家的角色、三槽(技能 / 等级 / 组合两半的原等级)、冷却与泡泡 / 冻结结束 Tick、朝向、回春计时;技能糖的技能与等级;着火格清单;主动技能输入;技能释放 / 进化 / 回血 / 技能糖拾取与掉落事件;技能表、组合表、角色表。火焰致死复用契约 `PlayerDied.Cause = 2`(燃烧),冰川弹复用 `BombKind` / `PierceLayers`。是否提给契约,等原型验证后另议。
