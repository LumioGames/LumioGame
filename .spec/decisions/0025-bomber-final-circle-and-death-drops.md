# 0025 · 炸弹人终局改为「最后一命决赛圈」,死亡掉落一半强化

- 日期:2026-09-25
- 状态:生效（「帽子照常全散」「宝箱不出帽子」等帽子资源条款被 0028 取代；「固定 90 秒、整局封顶 6 分钟」「安全圈 3 段」「圈外每秒 −0.5 心」「胜负仍按帽子数」「局末锁入 ≤ 90 秒」被 0031 取代）

## 背景

用户 2026-09-25 试玩 101 网页原型(ADR [0024](0024-per-game-directories-and-101-web-prototype.md))后提出四点:

1. 帽子规则不够明确;
2. 地图炸干净之后不再生成东西,后半局空旷;
3. 竞技性不够;提议「地图资源没了就不能复活、开始角逐第一名,随人数减少加缩圈,圈外中毒、圈随时间变小,资源没了时圈缩小并出现更强的宝箱」;
4. 死亡应随机掉落已吃的强化(火力+ / 炸弹+ / 速度+),复活后要变弱,而不是和之前一样强。

第 3、4 条与现行定调直接冲突:ADR [0014](0014-bomber-v04-stage0-convergence.md) 锁了「终局最后一分钟 = 演出不改计分……不用致死收缩圈」;`design.md` 支柱 3「死亡是节奏不是惩罚」明文否掉「死亡清糖果、出局观战」,§8.5 写「糖果不占槽、死亡不清」。

原型数据佐证了问题:无渲染整局测试里 8 个 Bot 6 分钟只有 2–3 次击杀,帽子全靠击杀发行,于是大部分时间全场 0 帽,帽子规则无从被看见;19×19 档按设计 Stage 0 不做软砖再生,积木 4–5 分钟即被炸完。

## 决策

- **引入「最后一命决赛圈」,取代 0014「终局只是演出、不用致死收缩圈」。** 用户在三个方向(最后一命决赛圈 / 缩圈但可复活 / 先不缩圈)里选了最后一命:
  - **触发:资源或时间先到先触发。** 剩余可破坏砖(积木 + 木箱,再生补回的计入)< 开局数量的 20%,或局时只剩 90 秒。
  - **固定 90 秒,整局仍封顶 6 分钟。** 资源先触发时局终同步提前(局终 = 触发 + 90 秒)。用户在「双触发」与「只看资源耗尽(局长不固定)」里选了双触发。
  - **决赛圈内死亡即出局:** 帽子照常全散、强化照常掉落、不再复活、观战到结算;触发时已在重生倒计时中的玩家照常复活一次。
  - **安全圈分段收缩,圈外中毒:** 19×19 档 13×13 → 9×9 → 7×7(触发后 10 / 40 / 70 秒),每段提前 10 秒预告;圈外每秒 −0.5 心、重生保护不免疫,毒死按自杀口径(不铸帽)。
  - **强力宝箱:** 每段预告时在下一圈内落 1 个,3 次独立命中开启,喷出火力+ / 炸弹+ / 速度+ 各 1 + 血包 1;不出帽子。
  - **存活 ≤ 1 人立即结算。**
- **胜负仍按帽子数,计分公式不变。** 用户在「帽子最多者赢」与「最后存活者赢」里选了前者:出局者帽子已全部散落,实际赢家是「活下来并抢到最多帽子的人」,帽子仍是唯一胜负语言(支柱 1)。0014 里「不加双倍分、不扣落后者分」这一半继续有效。
- **死亡掉落一半强化,取代支柱 3「否掉死亡清糖果」与 §8.5「死亡不清」。** 已吃强化每级 50% 概率掉落在死亡点周围,谁捡归谁,死者最低保留初始值;血包不掉。取值 50% 与装备的「每件 50% 落地」同口径,推断待验证(A/B 30% / 100%)。
- **支柱 3 改写为:** 常规阶段死亡代价 = 帽子全散 + 强化半掉 + 装备半掉,3 秒复活,仍否掉长重生 CD、死亡扣分、强化全清;**决赛圈是唯一的出局场景**,常规阶段不得引入出局。
- **局末锁入改为「决赛圈锁入」**(≤ 90 秒),取代 `design.md` §11 原「最后约 30 秒」。
- **帽子与强化的流向必须可见**(回应第 1 点):击杀「+1 帽」飞到击杀者头顶、拾取显示「+N」、开局倒数显示一句话规则。属可读性功能,记入 `design.md` §9.6。
- **软砖再生口径不变**:Stage 2 起大地图照常再生(决赛圈停止);19×19 档仍不做再生,资源耗尽由决赛圈的资源触发接住(回应第 2 点)。
- **锁与不锁:** 锁「最后一命决赛圈 + 帽子计分 + 双触发 + 90 秒 + 死亡掉一半强化 + 决赛圈是唯一出局场景」;不锁全部数值(20% 阈值、90 秒、圈尺寸与节奏、毒速、宝箱命中与内容、50% 掉率),全部进 `design.md` §15 待验证。

## 后果

- `design.md` 修订:§1 一句话规则、§2 核心循环、§3 支柱 3、§4 胜负与中途进出、§4.1 节奏表、新增 §4.2 决赛圈、§5 软砖再生、§8.5、§8.6 中央补给末次落点、§9.4、§9.6、§10、§10.1、§11 锁入、§12(新增毒圈一行、死亡 / 重生 / 观战)、§14 原则 9、§15 待验证项、§16 Stage 1 内容、§17.1 事件。
- **契约影响(本 ADR 不改契约):** `PlayerDied.Cause` 需要「毒圈」值(v2 只有 0/1/2);决赛圈状态(触发 Tick、当前圈、下一圈、存活 / 出局)与强力宝箱实体在契约 v2 里都没有位置。等原型验证后走契约修订另立卡;原型里一律标 NON-CONTRACT。
- **代价:支柱 3 与 4 各让出一块。** 决赛圈内的出局者最长观战约 90 秒;决赛圈期间中途加入者只能等下一局。接受:用 90 秒上限框住,换取后半局的竞技张力。没有快速重连(架构约束 3)时,决赛圈内掉线等于出局,同样由 90 秒上限兜住。
- **代价:死亡掉强化加重了死亡挫败感,并与「中途加入只补战力」的补偿量相互影响。** 由 A/B 30% / 100% 与 §17 遥测(复活后首杀时间、再来一局意愿)验证,不达标先调掉率。
- 0014 的状态改为「部分被 0025 取代」,其余条款(Stage 切片、官方房范围、补给、装备替换确认、HatPile 表示法、连锁结算口径、可读性清单)继续有效。
