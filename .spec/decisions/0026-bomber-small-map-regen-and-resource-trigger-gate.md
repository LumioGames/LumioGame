# 0026 · 19×19 档也做软砖再生,资源触发决赛圈只在再生停止后生效

- 日期:2026-09-25
- 状态:生效

## 背景

ADR [0025](0025-bomber-final-circle-and-death-drops.md) 定了「资源(剩余积木 < 20%)或时间(剩 90 秒)双触发」的决赛圈,并沿用 `design.md` §5「Stage 0 的 19×19 档不做再生」,由资源触发接住「炸空」。

同日在 101 网页原型里把 Bot 调凶之后实测:8 个 Bot 在 19×19 上约 28 秒就把积木炸掉 80%,资源触发几乎开局即点燃,一局中位只有约 2 分钟、击杀 2–3 次、帽王更替约 1.5 次,远低于 `design.md` §16 Stage 0b 的玩法门(六分钟内 ≥ 2 次帽王更替)。同时用户 2026-09-25 的反馈第 2 条正是「地图炸干净之后没有再生成东西,会很空旷」。

## 决策

- **19×19 档也做软砖再生**,取代 `design.md` §5「Stage 0 的 19×19 档不做再生」:常规阶段每 8 秒在无人区域补回至多 2 组四象限镜像积木(每组最多 4 格),直到可破坏砖回到开局的 60%;只长在砖层为空、非水、非出生安全区、格上无炸弹 / 糖果 / 帽堆 / 宝箱、离活人与炸弹 ≥ 3 格的位置(数值推断待验证)。
- **再生在距时间触发还剩 60 秒时停止;资源触发只在再生停止之后才生效。** 前半局地图不空,后半局资源真正耗尽才进决赛圈。
- 不改 0025 的其余条款(90 秒、最后一命、帽子计分、毒圈、宝箱、死亡掉强化)。
- **锁与不锁:** 锁「再生存在 + 资源触发晚于再生停止」这一结构;不锁 8 秒 / 2 组 / 60% / 60 秒 / 3 格等数值。

## 后果

- 原型实测(4 个种子,默认 6 分钟、7 Bot + 1 静止玩家):决赛圈均在第 3 分 30 秒由资源触发,一局 5 分钟;每局击杀 10–18 次,帽王更替 1–7 次;毒圈致死约占 15%。
- 资源触发在高强度对局里退化为「再生停止即触发」,实际等价于时间点触发;真人对局密度较低时两者才会分开。由 §15「决赛圈触发与时长」一项继续验证。
- 再生是低频批量方块写入,量级远低于爆炸破坏,符合架构约束 5。
