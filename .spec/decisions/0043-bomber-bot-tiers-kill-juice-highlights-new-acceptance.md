# 0043 · 炸弹人 Bot 分层(新增菜鸟档、不围剿真人)、击杀手感与成就感(高光卡、Boss 播报、里程碑、个人最佳),新验收 D / E 改为 16 人 · 27×27

- 日期:2026-09-28
- 状态:生效

## 背景

用户 2026-09-28 反馈「AI 机器人又有点强」「用户的爽感没有那么高……现在击杀会掉落一堆东西,这是爽感的一部分,但是其他爽感还没有体会到」,并在方向 B(ADR 0038)下要求成就感。读码结论:

- Bot 三档共用同一张「精确引信 + 连锁」危险图与 2 Tick 逃生余量,随机走位只走安全格——Bot 的失误从不致命;三档对脚本玩家的前三率 40 / 43 / 40%,几乎无差;7 个 Bot 同为 normal,没有「猎物层」。验收 D(脚本玩家对 7 个 normal 进前三 ≥ 50%)实测 42% 未达标。
- 击杀者在规则上零回报,单杀没有任何反馈(无弹字、音效、定帧、震屏);只有同链 ≥ 2 才有「双杀」;没有跨时间的连杀。

用户对成就感四项全选:局末高光卡、击倒 Boss 全场播报、连杀与连锁里程碑、个人最佳纪录。

## 决策

- **Bot 分层(原型工具)**:
  - 新增 `rookie`(菜鸟)档:反应 10–16 Tick、决策间隔 3 Tick、噪声 30%、放弃进攻 50%、不用技能、逃生余量 0 Tick(现 2)、每颗敌方炸弹 25% 把火力看小 1 格、30% 冒险穿危险区捡糖——让它们真会死、可被收割。随机数走新随机流,easy / normal / hard 序列不变。
  - 默认阵容(15 Bot):菜鸟 7 / 普通 6 / 困难 2;`?ai=` 仍可整体覆盖。
  - **不围剿真人**:真人作为目标 +6 分惩罚(真人是帽王或在 3 格内除外);只有离真人最近的 2 个 Bot 能选真人为目标(无状态规则,各 Bot 从同一快照算出同一结论)。由宿主把真人 id 传给 Bot(`softTargets`),不从快照猜。
- **击杀手感(纯表现层)**:单杀本人「击飞 XX!+N」弹字 + 专属击杀音(8 秒内音高递增)+ 定帧 70 ms + 镜头冲击;命中飘「−1♥」+ 命中音;死者掉落沿抛物线喷出(≥ 6 帽更大、金币串音效);整局最后一杀本地渲染慢镜 0.6 秒(只动渲染时钟)。
- **击倒 Boss 全场播报**:心数上限 ≥ 6 的玩家被击倒 →「XX 击倒了 N 心 Boss!」全场横幅 + 大号爆装喷泉(ADR 0039 的 Boss 口径)。
- **里程碑**:8 秒内连杀 双杀 / 三杀 / 四杀 / 暴走;不死连杀 3 / 5 / 8 → 大杀特杀 / 主宰 / 超神(本人横幅 + 击杀栏);首次 ×5、×8 连锁弹字。均由客户端从 `PlayerDied` / 连锁事件推导。
- **局末高光卡**:领奖台之后每人一张本局最亮眼的一项——按各人相对全场最突出的一项分配、尽量不重复;候选:最长连锁、最多击杀、帽王最久、拆迁王、Boss 猎人、绝境逃生(1 心活下来)、金心收藏家、搬运工。覆盖率 100%。
- **个人最佳**:浏览器本地记住最佳连锁、最多击杀、最好名次、帽王最久;刷新时结算页显示「新纪录!」;读写一律容错,读不到照常显示(约束 7:无账号持久化,正式版需账号级存储后再迁移)。
- **新验收**:
  - **D(卡门槛)**:普通水平脚本玩家(ADR 0036 口径,按时进圈)对 菜鸟 7 / 普通 6 / 困难 2,16 人 · 27×27,种子 1–100:**进前 4 ≥ 50%、K/D ≥ 1.0**;场均击杀作报告项。旧 8 人 D 降为只报告、不卡门槛。
  - **E**:全员 normal,16 人 · 27×27:唯一存活 ≥ 85%、平均局长 ≤ 4 分钟、1×1 每局可进入。
- **不选的方案**:连杀进入狂暴、击杀回血、赏金直入账(用户未选;狂暴只出自中央补给,ADR 0040);连锁爆糖、金积木(记为候选,本轮不做)。
- **锁与不锁**:锁「菜鸟档存在且会犯致命错误、默认阵容以菜鸟为主、不围剿真人、四项成就感、新 D / E 口径」;不锁各档参数、阵容比例、+6 / 2 个 / 3 格、弹字与音效细节、高光卡候选与分配算法、验收阈值,全部推断待验证,进 `design.md` §15。

## 后果

- **取代** ADR 0036 的验收 D 门槛口径(脚本玩家按时进圈、100 局的口径保留,对手阵容与地图改为本 ADR);`design.md` §3.1 爽感时刻表、§9.6、§13(高光卡、个人最佳)、§15 Bot 难度分档与相关行、§17 事件与指标修订。
- 旧统计基线(8 人 19×19、7 normal)不再作门槛;新基线在 M1 首次跑出后记录。
- **原型改动(M1)**:`contract/ai.ts`(rookie、`lineupFor`)、`bots/perception.ts`、`path-search.ts`、`danger-map.ts`、`behaviors.ts`、`bot-brain.ts`;`app/local-host.ts` 传 `botLineup` / `softTargets`;新建 `present/kill-juice.ts` 与 `present/personal-best.ts`;`hud/*` 弹字、横幅、高光卡;`audio/*`;统计工具 `tests/harness/*` 支持 16 人 · 27×27 与新指标。
- 代价:菜鸟 Bot 让对局更「割草」,可能削弱真人之间的竞技紧张感;正式版以真人为主时 Bot 只作填充,阵容比例按房间人数再调。
