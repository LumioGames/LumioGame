# 0007 · 美术风格框架推翻归零,进入三方向比稿

- 日期:2026-08-28
- 状态:生效

## 背景

`docs/specs/art-direction.md` 同日成稿,定了「手绘卡通 + 硬描边 + 有限色板 + 正交俯视 + Q 版 2D 八向角色」的完整框架;但该框架从未经用户定调流程拍板([0001](0001-art-director-skill-family.md) 同日明言「美术风格尚未确立,需从零定调」)。用户启动美术定调时明确选择**推翻归零、开放比稿**,并补充硬输入:产能主体是 AI(生图 / 生模型),整体基调休闲、轻松、愉快,娱乐社交向;从参考截图只取「暖色调亲和情绪」与「Q 版比例圆润造型」,不取软渲染承诺、不取 3D 角色。

## 决策

- **旧框架推翻归零**:`art-direction.md` 状态改「已推翻 · 存档」,全文降级为比稿方向 B 的详细参考;正式美术规范待比稿定调后按 art-bible 流程重建(落点仍循 [0002](0002-design-specs-landing-point.md))。
- **比稿边界(锁,候选不得越界)**:卡通基调;休闲轻松愉快、娱乐社交向;暖色亲和 + Q 版圆润;产线 = AI 主产能、场景体素单贴图无 PBR、角色 2D + 少量动画;产品层硬约束(俯视角玩法可读性、多人同屏识别、Windows 优先)不随美术框架一起推翻。
- **三方向比稿**:A 暖软绘本(Cozy Storybook)/ B 明快硬描边(Bold Pop,即旧框架方向以平等身份重新参赛)/ C 玩具质感(Tactile Toybox)。评估轴 = AI 产线一致性 × 竞技可读性 × 情绪贴合;运行时性能三者几乎相同,不作区分轴。
- **定调流程**:art-prompt 探索包出图(GPT / Gemini 类工具)→ 四关筛选(风格 / 结构 / 落地 / 合规)→ 用户拍板方向 → 提炼 3–5 条可证伪风格支柱 → 新 ADR + art-bible 落规范 → 风格验证包(一屏 UI + 1 角色 + 1 场景角 + 1 特效)进 B1 抛弃型原型实拍验证后才锁。
- 比稿工作产物落 `docs/specs/art-style-pitch.md`(探索稿,定调后由正式规范取代)。

## 后果

- B1「画面组合可能不好看」验证的画面方案悬置到比稿定调,抛弃型原型启动顺延。
- 旧稿中被下游引用的具体条款(俯角 55°–65°、1 格 = 1 米、硬描边缝合等)全部降级为**待比稿确认的假设**;[0006](0006-bomber-hat-scoring-rolling-room.md) B1 清单等处的引用按假设处理,不需回改。
- 若 C 方向胜出,「AI 生简模 → 引擎渲 8 向 sprite」的轻量 3D 环节将进入主产线,产线复杂度上升。
- 比稿期间 art-prompt / art-review 继续按 0001 的降级模式工作(显式标注假设,产出不具规范约束力)。
