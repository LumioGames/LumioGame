# 0032 · 炸弹人手感补充:同按两个方向走得通的那个、转角吸附 0.5 格、玩偶视觉占地不超过 0.7 格

- 日期:2026-09-26
- 状态:生效

## 背景

用户 2026-09-25 第 4 轮反馈:45° 视角下往右走容易卡脚卡墙;要求先排查根因(碰撞箱 0.8 格 vs 放大 1.3 倍的玩偶、转角吸附 0.4 格、键盘同按两方向),改为碰撞箱 0.7 格、吸附 0.5 格、同按两向时走通的那个、脚圈与影子对齐逻辑位置。

对原型代码只读排查(`games/101-bomber/prototype/src/sim/move.ts`、`src/input/keyboard.ts`、`src/view/world/dolls.ts`、`src/view/scene.ts`):
- **规则层没有碰撞箱。** 契约 v2(ADR [0021](0021-bomber-contract-v2-align-engine-second-exemplar.md))的移动是「四向 + 停」枚举;原型把玩家当作通道中心线上的一个点,只有转角吸附容差(400 / 重复 200 千分格)。全仓不存在 0.8 格碰撞箱。
- **同按两方向会停住:** 键盘只上报最后按下的方向;新方向走不通时,6 Tick 转角缓冲一过就原地停住,哪怕旧方向一路畅通。
- **晚按转弯救不回:** 基础速度每 Tick 175 千分格,6 Tick 缓冲只覆盖 1050;越过 0.4 格容差的晚按在下一个路口前就被拒。吸附放宽到 0.5 格后,最坏缺口 1000 ≤ 1050。
- **视觉放大:** 玩偶 ×1.3 后朝 ±x 前伸约 0.3–0.5 格,墙面离格心约 0.46–0.48 格,停在格心也像贴墙;方向光从左后方打来,头影朝 +x 偏约 0.8 格,**只有往右走**时正好投在前方墙面上——这是「往右」特别明显的原因。左右数值与按键映射完全对称,相机无偏航。

`design.md` §6.1 仍写「自由八向移动」,与契约四向冲突(契约胜)。

## 决策

- **§6.1 改为「四向 + 停」**(引用契约 v2),删除「自由八向」。
- **新增冻结手感规则「同按两个方向走得通的那个」:** 新按下的方向优先;它走不通时沿旧方向继续滑行(沿墙滑动),一旦走得通立即转入;两个都走不通才停。反方向键永不作为回退方向;自动选择永不把玩家带进危险方向。由规则层判定,客户端不读地形做决定。
- **转角吸附 0.4 → 0.5 格,连续转角的重复吸附 0.2 → 0.25 格**(保持 2:1);仍不把玩家吸进危险方向。
- **不引入碰撞箱,记录「0.8 格碰撞箱从未存在」。** 用户要的「0.7 格」落在视觉上:玩偶视觉占地 ≤ 0.7 格(脚圈直径 0.7、朝移动方向前伸 ≤ 0.35 格),停在墙前不与墙体视觉重叠;脚圈、接触阴影与双脚严格画在插值后的逻辑位置;方向光阴影不得把头影投到前方墙面上。
- **验收:** 自动化固定输入走「贴墙直行 → 拐进通道」等 10 条路径,卡住 Tick 数 = 0(卡住 = 至少一个按住的方向走得通,位置却没变)。
- **锁与不锁:** 锁「四向 + 同按两向走得通的那个 + 规则层无碰撞箱 + 视觉不越过墙面」;不锁 0.5 / 0.25 格、0.7 / 0.35 格、输入缓冲 125 ms、触屏摇杆判定第二方向的阈值,进 `design.md` §15。

## 后果

- `design.md` 修订:§6.1(四向、吸附阈值、新增两条)、§15 手感两行。
- **契约影响(本 ADR 不改契约):** `移动技能输入` 只带一个 `方向`;「同按两向」要把第二个方向带进规则层,原型以 NON-CONTRACT 扩展字段承载(字段名见原型 README);C# 落地时提契约修订,或在命令包络里以同语义实现。
- 视觉占地收窄会让玩偶显小,与帽子塔可读性(B6)互相影响,进 B1 画面验证。
- 吸附放宽后「误吸附进旁路」的机会增加,由 §15 继续验证。
